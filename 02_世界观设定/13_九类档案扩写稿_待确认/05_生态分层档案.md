# 05 生态分层档案

E01至E07是现场剖面编号。`0—20米`等深度以当次样方附近的冰顶或岩台为零点，地热、水位和空间页变化会使分区交错、缺失或重复。每张剖面只对应采样日期和图幅范围。

## 总能量口径

白渊大部分初级生产来自化能过程。微生物和共生体利用氢、甲烷、还原铁、硫化物和含氮化合物；冰岩磨碎持续暴露新鲜矿物表面。局部冰窗与人工光支持少量光合作用和趋光行为，其测得通量只覆盖群落总需求的一小部分。

现有热流与化学能模型可覆盖约60%至80%的宏观生物量。缺口在档案中称为“未核算代谢余量”。调查报告分别登记实测通量、模型误差和异常假说，工程试验至今没有获得稳定可采集的额外能量。

## E01 冰顶滴水层

### 连续观测
滴水量并不随地表气温同步变化。K4的薄冰顶在风压改变后数小时才出现增流，CN-SL2则常在地表降温时继续滴水。观测组以接水量、盐度、温度和滴点位移四项记录，每次至少持续七十二小时；单张“正在融化”的照片不进入水量序列。

绳索、灯具和人员体温会改变局部凝结。为避免把作业造成的湿痕当成常态，首次进入只布设无源标尺，第二次才取样。滴水层也是污染最容易向下传递的地方，燃料、润滑脂和消毒液一旦泄漏，后续三个层级的样本都要标注同一事故号。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 距局部冰顶0—20米 |
| 温度 | −8至0°C，滴水口短时接近0°C |
| 湿度与风 | 70%—100%；通风口附近0.5—6 m/s |
| 气体 | O2 19.5%—21.5%，CO2 0.06%—0.20% |
| 光 | 0.003—0.3 lux，来自冰体散射、裂缝或人工灯 |
| 基质 | 蓝冰、落冰锥、裸岩和薄盐膜 |

这是最接近地表空气交换的生境。滴水携带矿物粉、空气沉降物和少量微生物，沿冰顶裂缝形成断续带。生物量低，常见玻璃苔薄片、蓝孢沉积和小型白壳虫；大型动物只留下经过痕迹。

采样重点是滴水量、导电率、pH、盐分、悬浮物和微生物培养。落冰是主要人员风险。某段突然变亮先检查地表裂缝与营地照明，不把散射光当异常。

## E02 冰壁甲壳带

### 连续观测
甲壳带的可见厚度随水膜和照明角度变化，现场估算常比切片结果大一倍。固定样方每月只刮取边缘一小块，中心区域保留用于观察扩展速度。死亡甲壳、矿物薄膜和活体群落颜色相近，必须通过显微结构与复水反应分开。

人员通行会在冰壁留下热痕，数日后形成新的凝结边界。入口队若频繁扶墙或倚靠，会制造一条看似生长迅速的带状群落。因此生态卷把手套接触区、钢索摩擦区和天然样方分别编号，不合并统计。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 20—45米 |
| 温度 | −6至+1°C |
| 气体 | O2 19.0%—21.0%，CO2 0.08%—0.30% |
| 水 | 薄膜、盐卤和间歇滴流 |
| 基质 | 冰壁、盐壳、铁锈色矿膜和旧碳酸盐沉积 |

冰壁上的微生物膜和矿物壳构成狭窄生产带。薄甲壳与节肢样动物刮食膜层，白壳虫在此处数量最高。红脉地衣样群落沿少数暖岩裂面进入这一层，分布呈间断斑块。

现场用刮片、载玻片压片、培养、干重和色素萃取比较样方。脚灯会显著改变动物分布，观察记录必须写照明时长。盐壳下可能积存高CO2小囊腔，破壳前先取气。

## E03 蕨状低林层

### 连续观测
低林并非整齐的同龄植被。嫩叶集中在浅水沟和新裂隙旁，老株周围则堆积硬质叶片与根板碎屑。样方记录冠幅、叶片角度、地表水和伴生膜，连续两次观测之间若有道路施工，生长数据立即中断，不能跨越施工期连成趋势。

这层最容易被队伍误判为安全营地。低矮外形遮住根板孔洞，干叶在受热后会释放刺激性气味。通行规范要求沿既有踏线移动，帐篷底布不得压在完整株丛上；撤营后需复拍地面，确认没有把碎片带往其他生态层。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 45—90米 |
| 温度 | −6至+1°C |
| 湿度 | 85%—100% |
| 气体 | O2 18.8%—20.8%，CO2 0.12%—0.45% |
| 地面 | 黑泥、浅水、薄霜和密集根板脊 |

低矮孢子植物、根毡、玻璃苔和幼生拟木本组成过渡带。植被通常膝高以下，只有暖湿沟边达到腰部。这里连接多数小型入口与暮色针叶层，是任务最常反复经过的区域。

低林会遮住浅沟和根板空腔，常见事故是陷足、滑倒、滤芯堵塞和路线误认。样方记录叶片朝向、孢子沉降、根板纹理、地表含水量和比例尺照片。全景照用于定位，近距测量决定样方名称。

## E04 暮色针叶层

### 连续观测
黑针木的光合作用指标很弱，树脂和根部共生体却显示持续代谢。不同入口样本的针叶排列、维管组织和树脂成分存在稳定差异，暂不合并为单一物种。观察期内，枝条朝向更受水汽和暖岩影响，未发现可靠的“追光转向”。

针叶层改变了无线电、视线和导航。密林中三十米外的路标可能完全消失，潮湿树干会使短波定位产生偏差。行动图因此同时绘制地面桩号和树冠缺口，任何伐除都要记录树径、方位和木材去向。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 90—180米或大型岩盆地面 |
| 温度 | −4至+4°C |
| 气体 | O2 18.0%—21.0%，CO2 0.10%—0.60%；无风根层最高 |
| 光 | 背景0.001—0.03 lux，局部散射0.03—0.3 lux |
| 植被 | 1—3米黑针木为主，少数约4米；不接触顶板 |

黑针木和根部化能共生体构成最醒目的陆地生态，但针叶林只占白渊已确认地面的3%—6%。树体生长慢，树冠疏，地面仍有大片裸岩、黑泥和根板。银皮冷杉只在较亮或暖湿边缘形成小片。

大型动物密度很低。脚印、啃食面、粪便、湿痕和倒伏根板比直接目击更常见。调查队需把人工清路、自然兽道和空间记忆形成的交通线分开记录。常规林区接近全暗，所有可辨认照片必须有闪光、慢门或人造灯来源。

## E05 黑湖水系

### 连续观测
黑湖不是一片可直接连通的水面，而是由开阔水体、冰下支流、盐壳池和季节水道组成的水系。水位、压力和电导率在相邻井口之间并不同步，现有资料不足以证明所有探井通向同一湖盆。地图以水样相似度和声学推测区表示联系，不画成确定河道。

取样器下放会扰动水—气界面，并把套管上的微生物带入深处。每次采样同时设置空白瓶、套管擦拭样和回收水，三者任一出现同种污染物，湖水结果降为待复核。载人潜降仍被禁止，原因包括深度不闭合、救援能力不足及未知气体积聚。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 180—260米，或独立湖盆／暗河 |
| 水温 | 0—3°C，局部地热入流更高 |
| 水深 | 常见20—260米，个别推测超过600米 |
| 水化学 | 淡水、盐卤与层化水体并存；溶氧随深度变化 |
| 气体 | 岸边O2 18.2%—20.5%；低洼处CO2和甲烷可升高 |

黑湖水系由湖泊、暗河、压力水道和季节淹没区组成，部分水体只在高水位时相连。上层水可含氧，深层水和沉积物常处于低氧或缺氧状态，铁、硫、氮和甲烷循环在这里最明显。

盲银鱼、古两栖样动物和微生物膜是主要记录对象。声呐无底回波可能来自深水、软沉积、多重反射或设备角度，不自动等于无底。取水要同时记录深度、瓶号、温度和是否穿过化学跃层。

## E06 地热泥沼

### 连续观测
泥沼温度以成组探针测量，最热读数不代表整片区域。暖点常贴近裂隙，离开数十厘米便迅速下降；硫化氢和甲烷也呈斑块分布。作业前先用长杆探测承重层，再布设绳线，任何车辆都不得凭表面干壳判断可通行。

泥样在运输途中继续产气，密封瓶曾因压力升高破裂。此后容器保留膨胀余量，并把启封温度、气味和瓶内压力写进交接表。所谓“自行沸腾”的报告中，一部分来自减压与运输升温，只有现场连续温度曲线可以支持地热解释。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 260—320米或局部热异常斑块 |
| 温度 | +4至+18°C，极少数喷口更高但不作为人员区 |
| 面积 | 不足已确认地面的1% |
| 气体 | O2 18.0%—20.0%，CO2 0.20%—0.60%；可见H2S与甲烷风险 |
| 基质 | 黑泥、硫化物、热水沟和薄矿壳 |

地热泥沼生产力最高，也最不稳定。化能微生物、盐根毡、蓝孢蕨和大量小型分解者集中在暖边缘，真正高温喷口附近反而缺少大型生物。

表面硬壳与实际承重没有稳定关系。人员先用长杆探深并测量气体，车辆沿已验证路基通行。样本在升温和接触氧气后迅速变化，记录表按分钟填写取样、封口和固定时间。

## E07 根板与旧骨层

### 连续观测
根板把沉积、遗骸和活体组织压在同一层位，最容易制造年代混合。取样必须画出切口方向，分别封存根丝、附着物、骨片和周围沉积；整块撬走会毁掉相互关系。旧骨的物种、死亡时间和是否被搬运，现阶段分别列为独立问题。

这一层对道路最敏感。沉重设备压断根板后，数月内可能出现塌陷、积水和新的菌膜，旧路线因而不能永久视为安全。工程队每次回访都检查裂缝宽度、回声和标桩倾斜，生态记录直接进入通行等级评估，而不是作为行动结束后的附属采样。

| 字段 | 核定口径 |
|---|---|
| 标准剖面 | 320米以下或盆地沉积底部 |
| 温度 | −2至+6°C，受上覆生态与地热影响 |
| 气体 | 孔隙气O2可低于18%，CO2可高于0.6%；人员只在通风开挖面作业 |
| 厚度 | 局部旧骨和根板沉积超过80米 |
| 基质 | 木质根板、尸体、几丁质壳、矿泥和细层沉积 |

根板与旧骨层保存物质再循环和古环境记录。不同年代的根、壳、骨和矿泥被压成薄层，保存条件随水位与化学环境变化。大多数材料已经破碎，完整大型骨架很少，局部厚层由多次搬运和沉积叠成。

科学工作包括层位素描、薄片、骨骼比较、花粉与孢子计数、蛋白和矿物分析。开挖会释放CO2、硫化氢或甲烷，必须先打通风孔。若某具骨架位于不可能的层位，先检查滑塌、根系搬运和旧坑回填，再进入异常复核。

## 层间关系

- 冰顶滴水层向下输送水和氧化物，黑湖与地热带向上输送还原性物质。
- 暮色针叶层的根系会穿过低林和甲壳带，分区以群落、基质和水文共同确定。
- 动物会沿暖泉、盐地和低氧边界迁徙，生态地图必须标季节和测次。
- 空间页冲突会让同一入口在两次任务中落到不同层，但每份完成的样方记录保持稳定。
- 垂直剖面用于显示一次标准调查，图题应附日期、零点和适用图幅。
