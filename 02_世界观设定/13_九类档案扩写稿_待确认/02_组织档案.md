# 02 组织档案

本卷收录二十二个限制级机构与协作网络。每个机构的人员、经费、运输和办公地点都挂在公开部门名下，行动范围以战后早期实际调得到的资源为准。PALIS另列为档案系统，不计入组织总数。

## O01 美国南极测绘局（BAS）

| 字段 | 内容 |
|---|---|
| 英文 | Bureau of Antarctic Survey |
| 归档链 | 西方档案链 |
| 性质 | 美国跨部门限制级行政接口；无公开建制 |
| 公开挂靠 | 国家科学基金会项目、美国海军深冻行动、地质与气象项目、大学承包合同 |
| 秘密职责 | K系入口、林下站、航测校正、胶片与样本来源链、美国版白幕图幅 |
| 1964规模 | 华盛顿协调席、麦克默多归档副本、南极点站入口席、地平线站野外办公室；总知情人员控制在数百人内 |

BAS没有挂牌总部。华盛顿协调席掌握项目号、权限和跨部门交换，海军负责舰船、飞机和内陆运输，科研机构完成测量与实验，承包商供应井线设备、胶片、药品和冷藏箱。一次完整任务通常跨越三到五套账目。调阅者只拿到与本人岗位相符的部分，局长级人员也需要逐项申请实验室原始记录。

内部工作分为测绘校正、影像与胶片、样本与冷链、井线工程、人员复核和监管办公室联络六席。它们更像分散在不同机构里的联络桌，而非同楼办公的处室。文件保留项目原号、BAS归档号和监管办公室交换号。定密等级变化时，旧号留在封面或交接页，档案员据此追踪材料经历过几次改题和转手。

分拆制度也制造了大量缺段。大学能证明某件组织样本经过培养，却不知道采集位置；海军能证明一辆履带车离开南极点站，却看不到车上人员的真名；冲洗室保存完整胶卷，却只认卷号。合同结束、预算换项和责任转移会使这些局部事实再也无法在同一个案卷里汇合。

British Antarctic Survey从1962年开始使用BAS缩写。联合文件统一写`US-BAS`和`UK BAS`；美国内部公文仍可单写`BAS`。两套机构名称偶尔在电报和目录卡上被误并，南极公约监管办公室已把这种混淆列为独立的档案错误类型。

## O02 内陆特别作业局（USVR）

| 字段 | 内容 |
|---|---|
| 俄文工作名 | 暂未核定；USVR仅为拉丁字母档案缩写 |
| 归档链 | 东方行动链 |
| 性质 | 苏联科学院、国家水文气象体系、国防与内陆运输之间的封闭作业管理机构 |
| 公开外壳 | 苏联南极考察队、地震测深、冰川与气象、履带车路线建设 |
| 秘密职责 | D系井线、泰加站、长期驻扎、工程验收、失联队认领 |

局内按命令链分权。路线与运输、井线工程、科学解释、驻站政治与保卫、医疗隔离、档案复核各有负责人。现场站长有权中止一段路线，整张图幅的撤销需要莫斯科重新发令。编号改变以后，旧路线杆、油料缓存和人员记忆仍留在现场，工程队会同时携带新旧两套对照表。

苏联体系最大的能力是把人员、燃料和构件连续送到内陆并维持越冬。最大的风险也是同一件事：一份错误的验收记录会触发下一批物资、换班和宣传口径，最终形成有完整行政后果的错误版本。

1964年10月领导层更替后，赫鲁晓夫时期签署的西线项目进入复审。运输部门收到继续供给的旧令，科学院要求暂停测线，保卫部门则把部分井号从目录中撤下。三种批示在基层同时有效了数周。旧档分散在站务、工程和科学部门，任何单一销毁令都只覆盖其中一部分。

## O03 昆仑工程

| 字段 | 内容 |
|---|---|
| 性质 | 中国在无公开南极站网条件下维持的极小型跨机构工程 |
| 归档链 | 东方行动链 |
| 公开外壳 | 地球物理、冰川、地图、寒区工程、国际科学交换 |
| 秘密职责 | 1958事故复核、KL1/SL2/RS3节点、独立证据链和人员认领 |
| 资源边界 | 借用苏联运输，入口窄，无法持续运重型车辆 |

昆仑工程由核心科学组、交通联络组、样本保管组、口述复核组和临时现场队组成，没有统一挂牌机关。人员仍在科学院、测绘、地质、医疗和外事单位任职。交通联络组负责苏方名额与物资，样本组接收铅封箱，口述组在返程后组织分开笔录。命令和科学判断进入不同案卷，避免行政结论覆盖原始观察。

实物复核同时检查封签、重量、泥土、包装纤维、绳结和交接人。单独一件样本只证明容器里有什么，完整来源要靠沿途记录补齐。手绘地图与样本泥土冲突时，两份材料分别编号；地图继续用于路线调查，泥土交给不知道坐标的实验室复核。

资源依赖始终压着项目。每次借用苏方车辆都会暴露人数和目的地，分开口述又会延缓事故后的统一调度。上级有时要求尽快形成结论，复核组则坚持保留差异。昆仑工程依旧会记错、漏记，也会受政治影响，它留下的优势是错误发生时仍能看到原来的分叉。

## O04 北方联合考察委员会

| 字段 | 内容 |
|---|---|
| 成员骨架 | 英国、挪威、瑞典、丹麦；比利时等可按项目列席 |
| 归档链 | 西方档案链 |
| 性质 | 共享早期入口名额、原始胶片、地名和封存程序的协作委员会 |
| 地表锚点 | 哈雷、F站、锡格尼、希望湾及北大西洋档案转接线 |
| 地下节点 | 南森门、塔巴林吊舱井、圣露西陷口 |

委员会没有统一部队或单一国籍。英国提供档案、无线电和站网，挪威负责航线与地名，瑞典承担仪器和医学复核，丹麦处理文书与转运。每个成员保留本国副本，联合秘书处只规定交换页、复制代次和签收格式。

一次任务的材料经常分属四国。胶片在英国冲洗，拍摄者来自挪威，测量仪属于瑞典，转运封条由丹麦签发。会议首先确认哪一份是现场原件、哪一份是接触印样、谁有复制权，再讨论内容。所有权争议会拖慢调查，也使某一国难以单独撤回整条证据链。

委员会的常设人员不到一支完整现场队，大多数工作由成员国站点兼任。南森门和塔巴林吊舱井的名额按任务分配，圣露西陷口关闭后仍由委员会共同保管旧日记和入口图。预算不足时，行动规模先缩小，原件保管和多国复签继续维持。

## O05 南极公约监管办公室

| 字段 | 内容 |
|---|---|
| 英文工作名 | Antarctic Convention Oversight Authority（ACOA） |
| 归档链 | 联合与非结盟链 |
| 上级机构 | 联合国南极管理局（UNAA） |
| 历史前身 | 国联南极开发署（LNADA，1921—1946） |
| 性质 | 条约检查、秘密监察与跨国事故调停机构 |
| 成立依据 | 1961年条约生效后的《南极公约监督议定书》；不改变公开条约文本 |
| 职责 | 互斥坐标登记、跨国事故调停、人员交换、阅览权限、联合复核 |

监管办公室的档案血统早于《南极条约》。1921年成立的国联南极开发署曾汇总捕鲸航路、资源测绘、领土材料和远征事故。1946年国联结束后，其人员、地名卡、缩微卷和未结案卷移交联合国南极管理局；1961年，管理局把旧档案部门与条约事故办公室合并为南极公约监管办公室。

南极公约监管办公室依托条约国联络渠道运作，行政上接受联合国南极管理局的预算、任命和政治监督。它没有独立主权区或常备部队。常设班底由秘书、档案员和技术审查员组成，各国联络官在需要时组成临时调查组；车辆、飞机、警卫和实验室仍由提交国提供。

冲突材料到达后，工作人员把原国家编号、交换编号、来源链和调阅权限登记在同一案卷。会议决定谁能看原件、联合行动需要哪些国家参加、样本和人员由谁保管。关于记忆、地图和人员身份的最终判断留给有证据责任的调查组，南极公约监管办公室只记录各方结论及其依据。

这套机构常为维持合作压低措辞。某国要求立即封井，另一国坚持继续观测时，秘书处容易写出“加强监测”的折中决定。1964年西线事件使这一习惯受到质疑：调查组面对实体道路和空白工程账，临时行动口径已经无法代替现场停工命令。旧国联号、联合国管理号和PALIS交换号同时存在，也让任何一次删档都会留下另一条可追踪的来源链。

## PALIS极地档案联络与索引系统（系统条目，不计入组织）

| 字段 | 内容 |
|---|---|
| 全称 | Polar Archive Liaison & Index System |
| 所属 | 南极公约监管办公室 |
| 频道 | 09A为白幕联合记录频道 |
| 形态 | 穿孔卡、纸质目录、缩微胶片、电传查询和人工复签组成的索引制度 |

PALIS由穿孔卡、纸质目录、缩微胶片、电话与电传查询、加密电报码和人工复签组成。不同国家的原件仍留在各自档案库，PALIS只保存索引卡、摘要、权限、版本冲突和调阅轨迹。`INDEX READY`只表示目录可用，不表示材料已证实。

一次查询经过身份号、机构权限、主题号和来源链四项匹配。跨阵营条目通常只返回“存在”“限制”或“冲突”，调阅摘要需要单签，调阅原件需要提交国与南极公约监管办公室双签。同名人员、同坐标入口和外形相似的样本各自保留卡片，由档案员在卡缘挂交叉索引。

系统故障表现为1964年档案技术能够产生的错误：重复卡片、穿孔错位、复写页漏字、两份都通过人工校验的目录、同一卷缩微胶片配有不同说明。电话与电传查询有时间差，异地库房可能在数日内返回不同状态。PALIS不会实时修改原件，它造成的恐惧来自固定材料彼此排斥。

## O07 非结盟极地科学团

| 字段 | 内容 |
|---|---|
| 主要参与 | 印度、南斯拉夫及部分拉丁美洲科学家；成员以个人或机构项目加入 |
| 归档链 | 联合与非结盟链 |
| 性质 | 松散第三方资料网络；无自有基地和运输体系 |
| 工作 | 盲样、医学复核、翻译、论文交换、证词保管 |

科学团接收经过美苏拆分的样本、病历和摘要，安排不同实验室重复检测，再把结果存入贝尔格莱德、新德里或拉丁美洲的合作机构。样本来源经常被隐藏，实验报告只能描述组织、污染、蛋白条带和保存状态，采集地点仍由提供方负责证明。

成员国立场并不一致。有人追求科学独立，有人把资料当外交筹码，也有人只想保护回返者。松散结构避免单点销毁，也让术语和保密级别难以统一。

## O08 赫利俄斯工业联合体

| 字段 | 内容 |
|---|---|
| 性质 | 矿业、医药、运输、摄影、制冷和工程企业构成的商业掩护网 |
| 归档链 | 西方档案链 |
| 公开业务 | 寒区设备、胶片、药品、箱体、钻探和运输合同 |
| 秘密作用 | 样本拆分、设备采购、责任隔离、专利与商业试验 |

赫利俄斯由一批交叉持股、共用承包商和专利代理人的项目公司组成。矿业公司订购钢索与泵，制冷企业制作样本箱，摄影公司处理胶片，医药实验室接收提取物。联合体编号只出现在监管办公室索引里，普通员工看到的是一份有明确交货期和付款人的商业合同。

商业拆分会迅速切断科学来源。一件样本被分成二十份后，每份都有合法收货人、发票和实验目的，没有实验室见过完整形态。药理、材料和军用测试使用不同记录标准，负结果往往在合同结束后封存。资金、设备和人员仍受保险、海关、工会、事故赔偿及公司账目约束，这些外围文件也成为追踪样本的入口。

## O09 回返者观察组

| 字段 | 内容 |
|---|---|
| 成员 | 医生、档案员、少数幸存者、家属联络人和退役站务人员 |
| 归档链 | 联合与非结盟链 |
| 性质 | 半正式保护与复核网络，各国均不愿公开承认 |
| 职责 | 医疗随访、身份核验、记忆隔离、家属通知、二次归队风险观察 |

观察组接收回返者后，先核对旧伤、牙科片、指纹、血型、语言习惯、装备磨损和随身物，再进行事件访谈。记忆被列为证据的一部分，与医疗和实物记录分开保存。同一个人若能说出全部口令，却缺少旧骨折或牙科特征，观察期会自动延长。

保护与审查不可分。组员会阻止机构用限制级胶片诱导幸存者“想起来”，也会在身份无法闭合时限制其回家。它容易越界成秘密拘禁，因此每次观察都应留下医学理由、期限和复核人。

观察组没有全球总部。它依靠医院病历号、私人通信和少量监管办公室联络保持联系。各地医生只掌握自己的病例，监管办公室联络员负责比对。最严重的内部事故，是一名真实回返者因错误版本被长期隔离；此后所有延长观察都需要第二名医生和外部档案员复签。

## O10 美国南极研究计划协调办公室

| 字段 | 内容 |
|---|---|
| 公开依托 | 美国南极研究计划及国家科学基金会极地项目管理体系 |
| 归档链 | 西方档案链 |
| 性质 | 科学资助、站网计划与跨部门排期机构 |
| 公开职责 | 审核研究课题、协调船机运力、安排驻站与样本回运 |
| 白幕附加席位 | 从公开项目中分离异常测线，核对BAS提交的经费与人员名册 |

办公室不直接指挥井下行动。研究项目先以冰川、地震、气象或生理学名义获得经费，再由运输协调员把人员和设备嵌入海军航次。异常数据出现后，原项目仍继续结题，另制一份删去坐标的技术附页送往限制卷。这样既保住公开科学记录，也避免一处撤项使整条证据链消失。

它与美国南极测绘局并非上下级。前者掌握合法项目、预算和运力，后者掌握入口、胶片来源与封闭任务。两边的名单只有在人员失联、重伤或跨国复核时才完全对齐。

## O12 英国南极考察局（UK BAS）

| 字段 | 内容 |
|---|---|
| 公开沿革 | 由战时塔巴林行动及其后的福克兰群岛属地调查局发展而来，后改称British Antarctic Survey |
| 归档链 | 西方档案链 |
| 性质 | 英国常设南极科学与站网机构 |
| 公开职责 | 气象、地球物理、生物、测绘与基地运行 |
| 白幕附加席位 | 保管早期入口胶片、长波监听副本与北方委员会的英国档案 |

英国站网的优势不是重型运输，而是连续记录。哈雷、F站、锡格尼和希望湾留下不同学科的纸带、日志和人员更替表，足以复查某个呼号是否真的出现、某批样本是否曾经转运。限制卷只在原表旁增加交换号，不重抄原始数值。

UK BAS与美国BAS缩写相同，联合电报必须写国别前缀。曾有一箱胶片因缩写误判被送往麦克默多，箱体未拆封却在两国目录中各自产生一条“已接收”记录，此后同缩写文件必须核对站名、航次和签收人三项。

## O13 法国极地考察队（EPF）

| 字段 | 内容 |
|---|---|
| 公开沿革 | 战后建立的Expéditions Polaires Françaises |
| 归档链 | 西方档案链 |
| 性质 | 以远征组织、科学协调和技术保障为核心的法国极地机构 |
| 公开职责 | 南极沿岸站、内陆测线、地磁、气象、冰川与生物调查 |
| 白幕附加席位 | 维护夏尔科斜廊与奥尔菲探井的影像、盐壳及水样档案 |

法国卷宗坚持保留原始帧号和法语地名。联合地图可以附译名，却不得覆盖底片盒上的旧称；这一做法在多国坐标争议中常比统一命名更有用。

## O19 民主德国科学院南极协作工作组（AG Antarktis）

| 字段 | 内容 |
|---|---|
| 公开依托 | 民主德国科学家自1959年前后起持续参加苏联南极考察，项目涉及气象、冰川测地、电离层、重力与医学 |
| 归档链 | 东方行动链 |
| 性质 | 民主德国科学院内部的跨研究所联络组；AG Antarktis为限制卷工作称呼 |
| 公开外壳 | 随苏联考察队派出客座研究员，承担仪器维护、观测和回国数据处理 |
| 秘密职责 | 复核D系井线的光学测距、电离层时差、人员生理记录与德语器材铭牌 |
| 常驻规模 | 柏林与波茨坦共九名固定联络员；南极现场每季通常二至五人，无独立船队和基地 |

工作组的名单分散在科学院外事处、研究所人事表和苏方远征名册中。波茨坦负责重力与测地，柏林处理医学和无线电资料，耶拿工厂提供光学器材。南极现场的东德研究员编入苏方班组，使用苏方呼号；回国以后，原始纸带、仪器检修单和个人笔记才在工作组手里重新会合。

限制席最常接触的是测距镜、经纬仪、长焦镜头和记录鼓。器材出厂时已有德文序号，苏方入库后再盖一层俄文资产号，井线现场还会添临时编号。三层号码没有固定对应关系。工作组因此保留铭牌拓片、螺钉位置和镜片划痕，用来判断照片里出现的仪器究竟是哪一台。

东德人员不能单独批准进入，也无权调动履带车。他们通过USVR获得路线和床位，通过苏联南极考察队总局领取公开任务。遇到人员伤亡，医学记录先回苏方，家属通知和国内人事处理由东德方面接手。两边对事故措辞不一致时，工作组往往先封存德文原稿，等待下一次外交通道开放。

工作组内部保留一份“未归还器材册”。册中有些仪器已被苏方报废，有些仍在白幕井线出现，还有几台在两个站点同时完成年度检定。档案员不把重复记录合并，逐页附上签字、纸张和墨水差异，供后续人员判断是转抄错误、换壳维修，还是设备闭合失败。

## O20 波兰科学院本格尔绿洲地球物理分组

| 字段 | 内容 |
|---|---|
| 公开依托 | 苏联绿洲站在1958年底移交波兰，次年由波兰科学院接收并命名为多布罗沃尔斯基站 |
| 归档链 | 东方行动链 |
| 性质 | 波兰科学院地球物理研究体系中的小型南极资料与复测分组 |
| 公开外壳 | 保管多布罗沃尔斯基站设施，整理地磁、气象、测量和绿洲地质资料 |
| 秘密职责 | 维护东南极独立坐标副本，复核苏方移交设备和D系外围磁场记录 |
| 资源边界 | 无连续补给线；现场复测依附苏联航次，华沙只常设六人资料席 |

移交给波兰的不只是两座木屋。房间清单、磁力仪、测量桩、旧燃料桶和苏方留下的地名一起进入波兰卷宗。分组逐件重编资产号，却保留原有铭牌和俄文登记页。某件设备若在移交表上存在、在现场找不到，状态写“未见实物”，不会直接报失。

本格尔绿洲远离东方主井线，价值在于它能提供一条不经过莫斯科值班室的时间基准。磁扰、无线电静默和天气突变先写入波兰表格，航次结束后才送回华沙。USVR申请调阅时只能取得复制件；原始纸带由波兰科学院保管，除非派员到场共同开封。

分组没有能力维持全年行动。一次复测通常由四名地球物理人员和一名苏方联络员完成，在旧站停留数周。电池、帐篷和食品来自苏联船队，精密电表和记录纸由波方自带。补给推迟时，队伍优先封存仪器与底稿，入口搜索和长距离路线测量随即取消。

这份独立性让它在东方阵营内部显得难处理。苏方认为旧站已经完成移交，波方却发现若干设备仍被列入苏联年度检定册。AG Antarktis又在一批东德照片上认出同型号磁力仪。三方于是共同建立“绿洲器材对照卷”，它后来成为调查重复设备记录的主要样本。

## O21 捷克斯洛伐克科学院南极仪器协作室

| 字段 | 内容 |
|---|---|
| 公开依托 | 捷克斯洛伐克科学家曾以个人和小组形式参加苏联南极考察，国内具备光学、精密机械和低温仪器工业 |
| 归档链 | 东方行动链 |
| 性质 | 科学院、布拉格高校与国营仪器厂之间的限制级试验室 |
| 公开外壳 | 为高纬气象、天文和地球物理项目研制低温记录器、密封件与计时装置 |
| 秘密职责 | 检查井下记录器的走时误差、材料脆裂和异常复写；保存未交付样机 |
| 现场规模 | 通常只派一至三名工程师随苏联队行动，主要工作留在布拉格和布尔诺完成 |

协作室占用的不是一座独立研究所，而是几间恒温室、计量台和国营工厂夜班。送检仪器以普通气象设备入库，井下使用痕迹写成“低温冲击”或“运输损伤”。工程师拆下齿轮、胶圈和纸带组件，分别交给不同车间，只有总装记录保留白幕交换号。

这里擅长检查时间。机械钟、记录鼓和继电器同时放入低温箱，每隔固定时段由独立石英基准校对。若一台记录器声称运行十二小时，润滑脂状态、纸带长度和发条余量却只支持九小时，实验室会把三项结果分别签字。它不替现场解释缺失的三小时。

捷方人员很少知道入口坐标。苏方交付时会拆去地名，只留下温度曲线、压力范围和设备编号。保密减少了泄露，也使实验室无法判断两批“不同地点”的设备是否经历过同一次事故。为防止样机被调包，协作室在外壳内侧打入极小的三角冲点，位置只记在纸质装配卡上。

协作室与USVR的矛盾集中在交付期限。路线部门希望立即得到可用结论，工程师则要求完成多轮冷热循环。赶工件会贴红色斜签，表示它只通过一次复测。井线事故调查若引用这类报告，必须同时附上斜签照片，不能把临时判断抄成正式鉴定。

## O23 联合国南极管理局（UNAA）

| 字段 | 内容 |
|---|---|
| 英文名 | United Nations Antarctic Administration（UNAA） |
| 归档链 | 联合与非结盟链 |
| 机构权限 | 联合国南极行政、预算与跨国协调机构 |
| 前身资产 | 1946年接收国联南极开发署的人员、地图、事故卷与保管责任 |
| 下属机构 | 南极公约监管办公室；公开技术秘书处与运输协调席 |
| 权限边界 | 不拥有南极主权、常备军或独立入口；不能取代条约国现场机构 |

联合国南极管理局成立于1946年，最初任务是接收国联南极开发署遗留资产，防止捕鲸、航路、地名和远征事故档案在国联解散时散失。公开预算写作地图整理、技术协作和救援协调，限制卷则保存国联时期的异常航片、资源样本与未结人员案。

管理局不是南极政府。成员国仍掌握基地、船舶、飞机、入口和原始档案，管理局只能通过预算、观察员名额、联合救援与档案交换形成约束。美苏都拒绝让其直接检查本国重型井线，较小国家则利用管理局保留本国地名和事故版本，避免联合目录完全由大国书写。

1959—1961年间，管理局参与拟定《南极公约监督议定书》，并将事故办公室、国联遗档部门和跨国检查联络席改组为南极公约监管办公室。管理局负责署长任命、年度预算和政治交涉；监管办公室负责具体检查、事故调停、人员状态和PALIS运行。两者不能混称，PALIS更不能反过来代表管理局。

1964年西线事件中，管理局只收到删去入口坐标的政治摘要。是否停工、哪些国家参加调查、人员能否取得联合救援身份，由监管办公室提出方案，再交管理局和参与国复签。这个层级使联合机构看似权力庞大，实际每一步都依赖成员国合作。
