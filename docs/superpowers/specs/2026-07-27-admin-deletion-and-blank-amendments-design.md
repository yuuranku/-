# 管理员档案删除与自由修订页设计

## 目标

让管理员能永久删除任意正式档案；同时将科考站点、白渊入口，以及所有既有档案的修订投稿，统一为可自由添加内容的空白补充页。

## 规则

- 只有 `admin` 能查看全量正式档案和执行永久删除；书记官与观察员没有该入口和数据库删除权限。
- 删除针对 `archives` 的正式档案记录。删除成功后，其级联关联的投稿、版本、审核、引用和公开目录卡片不再存在。
- 删除前必须显示档案编号与标题，并要求管理员输入该档案编号作二次确认；不匹配时不发出删除请求。
- 管理员目录列出公开、封存、离线的所有正式档案，可按编号或标题筛选。
- 科考站点（`station`）和白渊入口（`entrance`）在书记官工作台不再显示新建入口，只能选择已有正式档案并创建修订投稿。
- 所有类型的修订投稿都使用同一张自由补充页：原档案基本信息只读；投稿人填写补充标题、正文，并可添加任意数量的“条目名称 / 条目内容”字段。
- 自由补充页在审核预览和正式档案渲染中以“修订补充”呈现；管理员可审核、退回或正式录入。它不改写原档案，直到管理员完成正式录入。

## 架构

前端客户端增加管理员专用的全档案查询与删除方法，直接使用已有 RLS 中 `archives_admin_write` 的管理员策略。工作台增加独立的“档案管理”窗口，用编号确认保护删除操作；删除成功后刷新管理列表并广播现有公开目录同步事件。

编辑器将 `station`、`entrance` 的新建入口禁用，修订动作改为复用一个 `amendment` 空白页数据模型。该模型在现有 `draft_content` 内保存，避免新表或迁移；正式录入仍通过既有投稿、审核与发布流程处理。

## 验收标准

1. 管理员能在工作台检索任一正式档案，输入正确编号后永久删除，列表和公开目录刷新后都不再显示该档案。
2. 编号不匹配、取消确认、非管理员均不会产生删除请求。
3. 科考站点、白渊入口不再允许新建，已有档案可以进入空白修订页。
4. 其余类别的修订同样使用空白补充页，并可保存补充标题、正文和多个自定义条目。
5. 现有新建档案、审核与正式录入流程保持可用。

## 非目标

- 不改变既有静态示例档案或档案目录视觉主题。
- 不在本次新增富文本编辑器、文件批量删除或回收站；删除是管理员确认后的永久操作。
