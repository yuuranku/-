# Fusion Pixel Font

- Project: Fusion Pixel Font
- Upstream: https://github.com/TakWolf/fusion-pixel-font
- Release: 2026.07.20
- Language subset: Simplified Chinese (`zh_hans`)
- Included sizes: 10px and 12px, proportional and monospaced
- License: SIL Open Font License 1.1 (`OFL.txt`)

The proportional faces are used for PALIS interface copy. The monospaced
faces are reserved for terminal output, codes, counters, and system chrome.
