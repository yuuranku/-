# 组织与事件档案复用原版排版

## 目标

组织档案与事件档案的正式页不再使用通用正式档案头部、元数据表或重新组合的版式。它们必须直接采用网站原始档案系统的视觉骨架，同时继续读取书记官表单保存的数据。

## 组织档案

- 使用原版 `chain-mast` 作为标题区：档案格式与编号在上，组织名称为主标题。
- 使用原版 `chain-columns`：左侧固定显示 `MANDATE / AUTHORITY / SOURCE CHAIN`，右侧为六项固定字段的两列原版字段表。
- 固定字段为空时不渲染空白内容；自定义标题和正文继续按原版链式正文区排布。
- 收录信息与版本信息只保留在页尾；不在头图或标题区重复出现。

## 事件档案

- 使用原版 `reel-mast`：左侧为档案格式与事件名称，右侧为事件日期。
- 使用原版 `reel-transcript`：左侧固定显示 `INCIDENT DOSSIER / CUT`，右侧为六项固定字段的两列原版字段表。
- 自定义标题与正文继续走原版事件正文结构。
- 事件印章保留，但放入原版标题区的右侧留白，不覆盖标题或日期。

## 共同规则

- 不保留通用正式档案的标题、分隔线与顶部元数据表；页尾元数据保留。
- 图片和注释功能保留在正文末尾，不改变原版标题区与固定字段区。
- 复用现有原版 CSS 类，不引入新的页面风格、渐变或动画。
- 以正式页渲染测试验证组织、事件的原版类名、固定字段位置、印章、正文图片注释，以及不出现通用头部。

## 验收标准

1. 组织正式页出现 `chain-mast` 与 `chain-columns`。
2. 事件正式页出现 `reel-mast` 与 `reel-transcript`。
3. 两类页面不显示通用正式档案头部或顶部元数据表。
4. 所有表单数据、正文附图和注释仍能在正式页读取。
