# 工作台邮筒摆件

## 目标

将工作台里的“档案邮筒”从桌面快捷方式替换为一个独立的普通邮箱摆件。它只在书记官工作台中出现，不改变加载页、档案页或既有 PALIS 吉祥物。

## 外观与层级

- 使用现有本地 `archive-inbox.svg` 图标，不新增外部素材或网络请求。
- 采用现有 Win95 / 档案工作台的金属边框、米白面板和深色字色；不使用吉祥物造型。
- 摆件在工作台的专用覆盖层中渲染，层级高于便签、桌面图标及工作窗口，但低于浏览器原生对话框。
- 有待办时右上角显示红色 `!`，不遮挡邮箱主体。

## 交互

- 点击摆件：书记官打开审核回信；管理员打开审核与录入队列。
- 拖拽摆件可在工作台视口内移动；拖动结束后保留本次会话位置。
- 未读的书记官批复在打开回信时标为已读；管理员待审核或待录入项目存在时保持提醒。
- 工作台关闭或加载页期间，摆件不显示。

## 数据与回归

- 继续调用既有 `listNotifications`、`markNotificationRead` 和 `listReviewQueue`，不复制通知数据。
- 提交成功文案继续提示“已投递至邮筒 / 等待审核”。
- 测试覆盖：摆件存在、桌面图标移除、角色路由、提醒数据源和已读联动。
