# 01 国家档案（1964）

本卷按N01—N18编列。领导层以档案期末的在任名单为准，年内换届另附交接日期。经济和军事实力只作结构判断，不录入来源不明的精确数字。

## N01 中国

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 中华人民共和国。中共中央主席毛泽东，国家主席刘少奇，国务院总理周恩来 |
| 1964年变化 | 10月16日完成首次原子弹试验；中苏分歧公开化；国内仍在“大跃进”后的经济调整期 |
| 经济 | 以计划经济和恢复农业、基础工业为主，外汇、远洋运输与极地专用装备都紧张 |
| 军事 | 大陆陆军规模大，核能力刚进入验证阶段；远洋和南极投送能力不足 |
| 南极公开活动 | 国家南极计划始于1981年；档案期内没有中国公开站网 |

1964年的中国没有通往南极的公开国家运输线。昆仑工程借用苏联东方站的人员名额和货运舱位，把测绘仪、地磁设备、药品和空白记录纸夹在公开科研物资中运入内陆。货物到达海燕中转点后重新编号，苏文装箱单留在地表，中方人员只带手写副本进入昆仑一号旧井线。松岭裂口承担短程人员出入，红签探井只回收仪器和水样。三处节点都依赖苏方燃料、履带车和远程电台。

1958年联合队事故改变了项目的记录习惯。返程人员先被分开安置，各自画出路线、标记听到的呼号，再核对靴底泥样、绳结、样袋铅封和腕表时间。整理员在比对完成前看不到其他人的口述。相互冲突的地图继续存档，图上用红框标出分歧，不再誊成一张“正确路线”。这一套办法在1964年已经成为昆仑工程最稳定的制度遗产。

中方卷宗直接探明约6.1万平方公里，其中能够定期复测、布置标记并安排回收的区域约1.34万平方公里。L2末段以外的记录越来越依赖苏联中继，许多图幅只有中文路线注记，没有可独立核对的地表坐标。现存材料以铅封样袋、复写纸地图、口述差异表和1958年人员名册为主。档案里没有中国公开南极站、专用破冰船或独立航空队的记录。

## N02 丹麦

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；国王弗雷德里克九世，首相延斯·奥托·克拉格 |
| 政治 | 北约成员，议会民主；格陵兰仍在丹麦王国内，极地行政经验主要来自北极 |
| 经济 | 高收入工业与农业经济，商船、制冷、无线电和行政能力强，规模有限 |
| 军事 | 以北约北翼、防空与海上通道为重点，不具备独立南极重型行动能力 |
| 南极公开活动 | 1964年主要承担极地行政、航运和北方委员会协作，现场份额较小 |

丹麦在北方联合考察委员会中占有一个很窄的席位，工作集中在文书、医疗和运输换算。格陵兰的寒区行政经验被整理成低温伤员表、狗队和雪橇负载换算表、无线电值班格式，再交给英挪现场人员使用。丹麦技术员偶尔随委员会小队从南森门或塔巴林吊舱井下降，名义身份通常是医生、通信员或仪器校准员，工资和保险仍由原单位支付。

哥本哈根保存的材料很少描述林下景观。档案箱里常见的是邮袋重量、转机名单、医院入院号、药品批号和第二代复印件。原件经过英国部门重新归档后，旧编号有时只剩在丹麦复印件的页眉和装订孔旁。1961年一批北方委员会医疗表被统一换版，丹麦库房仍留着旧版空白表，由此证明数份“后来才建立”的伤员记录早已存在。

丹麦没有自己的下降井、地下营地或独立控制区。它对行动的影响来自留痕：人员经过机场要有名单，伤员进入医院要有号码，密封样本跨境要有报关重量。大型参与国可以撤回一份报告，却很难同时清除这些分散在交通、医疗和邮政系统里的旁证。

## N03 南斯拉夫

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 南斯拉夫社会主义联邦共和国；总统约瑟普·布罗兹·铁托 |
| 政治 | 共产党领导的联邦制国家，脱离苏联直接控制，是非结盟运动核心 |
| 经济 | 社会主义市场与工人自治并存，接受东西方贸易和信贷，地区发展不均 |
| 军事 | 维持独立国防和动员体系，强调不依附华约或北约 |
| 南极公开活动 | 没有独立南极站网和持续投送能力 |

贝尔格莱德的非结盟极地科学团没有固定的“白渊科室”。材料分别进入大学医院、地质研究所、航运档案和外交部科学合作卷。美国送来的证词常被拆成病历、设备故障说明和无坐标岩样；苏联交来的文件则保留路线号和命令编号，删去人员真名。翻译员把两套术语并排记在卡片上，遇到无法对应的地名便保留原文，不替任何一方选定标准称呼。

南斯拉夫人员很少抵达南极。其作用发生在回程之后：安排第三方医生检查冻伤和记忆缺段，让地质人员在不知道来源的情况下描述岩片，再把结果分别寄回提供方。一名回返者在美方档案中可能是承包商，在苏方材料里可能被列作越界人员；贝尔格莱德只保存病历号、检查日期和送检人的签字。三套身份互相冲突时，病理切片仍能证明同一个身体接受过检查。

这批材料也带着南斯拉夫自身的误差。塞尔维亚-克罗地亚语、英语、俄语和法语转译会改变技术词义，外交部门有时为换取设备或贷款延迟移交原件。1964年的资料库提供了美苏之外的第三条来源链，却没有天然的裁决权。

## N04 南非

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 南非共和国；国家总统C·R·斯瓦特，总理亨德里克·维沃尔德 |
| 政治 | 国民党统治，种族隔离制度持续强化；国际处境日益孤立 |
| 经济 | 矿业、港口、铁路和工业基础较强，依赖被制度性压迫的黑人劳动力 |
| 军事 | 区域军力和海上补给能力较强，关注南大西洋—印度洋航道 |
| 南极公开活动 | 南极条约原始签署国，有南大洋航线和SANAE站务基础 |

开普敦是公约监督体系南大西洋方向的重要装船口。泵、绞车零件、矿灯、钢索和压缩气瓶可以按矿业设备报关，随常规南极补给船南下。港口文件能核对箱号、装船日期、毛重、承运舱位和卸货站，却追踪不到物资离开南极海岸后的去向。白渊档案因此常把南非单据当作“抵达大陆”的证明，而不把它当作地下交付证明。

南非气象部门提供好望角至南大洋的航线记录，海军和商船人员熟悉风暴、海冰与改港条件。1964年西线补给改期时，开普敦电报比美英任务报告早两天记录了船期变化。这类边缘记录可以排除某些并未发生的运输，却解释不了箱子在两个入口账本里同时出现的情况。

种族隔离制度直接破坏了人员统计。非白人装卸工、厨工和技术人员常被排除在正式乘员表之外，只在工资册、医疗登记或港区通行证中留下姓名。南极公约监督署早期把这类人数差异归入异常，后来复核发现其中相当一部分源自行政治理。南非卷宗必须同时保留港口能力和制度性抹除造成的缺口。

## N05 印度

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 印度共和国；总统萨瓦帕利·拉达克里希南。尼赫鲁5月27日去世，南达两度短暂代理，拉尔·巴哈杜尔·夏斯特里6月起任总理 |
| 政治 | 议会民主与非结盟外交；1962年中印战争后仍在调整安全政策 |
| 经济 | 混合经济与五年计划，重工业建设推进，但外汇、粮食和基础设施压力明显 |
| 军事 | 陆军扩充并重整山地防务，远洋与南极投送能力有限 |
| 南极公开活动 | 印度国家南极考察始于1981年；档案期内没有站点或公开项目 |

印度在1964年没有国家南极考察计划，接触白渊的地点主要在德里、加尔各答和国际会议会场。非结盟极地科学团把回返者的神经检查表、冻伤照片和去除来源标签的组织切片交给印度医生。海洋学和生理学研究人员收到的样本只标温度、固定液和采集深度，不附国家、入口或行动名称。

这种盲审安排产生过几份重要反证。加尔各答的一组代谢试验把“植物组织”判为含有大量共生微生物的复合样本，德里医生则在两名互不相识的回返者身上记录到相似的时间定向障碍。报告按普通学术交换件寄回贝尔格莱德，封面没有白渊字样，正文也没有南极坐标。

印度的参与受运输和外交条件限制。研究人员可以检查切片、统计症状和参加闭门讨论，现场钻井、入口测绘和人员搜救仍由有南极站网的国家承担。印度卷宗由会议附件、医院编号、海运样本收据和研究所实验记录组成，没有印度南极站或国家极地船队的条目。

## N06 德国

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 分裂为联邦德国与民主德国。西德总统海因里希·吕布克、总理路德维希·艾哈德；东德由瓦尔特·乌布利希主导，奥托·格罗提渥9月去世后维利·斯多夫任部长会议主席 |
| 政治 | 柏林墙已建成，两个德国分别嵌入北约与华约体系 |
| 经济 | 西德处于“经济奇迹”后期；东德为计划经济和华约工业体系的重要部分 |
| 军事 | 西德国防军与东德国家人民军隔墙对峙，均无独立南极行动线 |
| 南极公开活动 | 1938—39德国南极航测构成重要前史；1964年德国以档案、仪器与分析渠道参与 |

德国材料分成三个年代层。1938至1939年的航测留下照片、飞行日志、磁测带和临时地名；1945年以后，美、苏、英分别接收人员、设备和抄件；1964年的东西德学者只能通过战后分散收藏重新核对。三层材料的纸张、术语和编号体系不同，档案员可以据此判断一份“战时原件”是否在战后重新誊写。

美方掌握较完整的影像和承包商资料，苏方保存部分工程人员审讯与设备清单，英国卷宗中夹有早期地图转抄。原始航片没有拍到完整入口，只记录了几段反常的黑色低反射区和无法闭合的航线里程。后来的白渊调查借用了这些旧德文地名定位局部图幅，许多名称已经与同期地形脱离。

1964年复核出现一个难以解释的结果：一张比例粗糙、控制点不足的战前图，在六公里范围内比联合测绘图更贴合地表重力异常。档案没有证据表明德国远征掌握过白渊全貌。它留下的是一组早期观测，而这些观测在局部躲过了后来才出现的空间页偏移。

## N07 挪威

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；国王奥拉夫五世，首相埃纳尔·格哈德森 |
| 政治 | 北约成员，有明确极地传统和毛德皇后地利益 |
| 经济 | 航运、渔业、工业和水电重要，1964年尚未进入北海石油繁荣期 |
| 军事 | 重点在北大西洋与北极防务，南极行动以民用航海和科考经验为主 |
| 南极公开活动 | 极地航海、捕鲸、制图与挪英瑞联合考察传统深厚 |

挪威在北方委员会中的地位来自领航、测绘和私人日记。参与发现南森门的领航员用太阳方位、罗盘偏差、雪橇里程和沿途补给点重建路线。圣露西陷口关闭前的最后一次完整记录也出自挪威小队，日记逐日写明天气、行程、绳长和路标状态。两处入口由委员会共同使用，重型绞车和长期营地仍由英方或联合预算维持。

挪威档案保留地名的最早用法。英国、丹麦和后来的监督署图幅给同一山脊使用不同名称时，奥斯陆和私人收藏中的底稿仍附有命名日期、观测位置和书写者。地图复核人员由此可以判断名称是现场产生，还是回国后为了主权和归档重新添加。

捕鲸船和商船报告构成另一层材料。它们能提供某日的海况、冰缘、航线和岸上灯光，却缺乏稳定的测量条件。档案员把这类目击记在航路附表里，不与科学观测混编。南森门和圣露西陷口的地下范围没有被划成挪威领区，卷宗只记录委员会共享的行动里程。

## N08 新西兰

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；伊丽莎白二世为女王，总督伯纳德·弗格森，首相基思·霍利约克 |
| 政治 | 议会民主，处在英联邦和美国安全体系内 |
| 经济 | 以农业出口为基础，对英国市场依赖高，具备可靠但规模有限的工程与航空保障 |
| 军事 | 小型专业军队，参与西方联盟；南极能力以罗斯海后勤为主 |
| 南极公开活动 | 斯科特基地1957年启用，支持英联邦横越南极远征和国际地球物理年 |

斯科特基地处在美国罗斯海后勤和英联邦记录体系之间。新西兰气象员记录能见度、云底、横风和跑道状态，通信室保存与麦克默多互通的班机和车辆消息。有人声称在某日从内陆回到地表时，调查员先查斯科特基地的天气簿和厨房配给，再查美方飞行记录。两套材料分属不同国家，事后同时改动的难度很高。

新西兰没有独立下降点。人员按任务借用美国K系入口或澳大利亚威尔克斯湿门，名单上多以气象、工程或无线电岗位出现。地表转运使用既有车辆和航线，地下行程由入口控制方另行记录。斯科特基地只知道某人何时离开罗斯海、带走多少行李，以及是否按期返回。

澳新联合图稳定直接探明约4.5万平方公里。面积来自共同测线、航片和入口方记录，按每次任务的实际来源分别登记。新西兰保存较完整的班机、无线电和中转签名，因此在人员时间线复核中份量很重；深部地图、样本分类和入口工程仍掌握在美澳机构手中。

## N09 日本

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；昭和天皇。池田勇人任首相至11月9日，佐藤荣作继任 |
| 政治 | 自由民主党长期执政，与美国结盟；东京奥运会在1964年举行 |
| 经济 | 高速增长期，制造业、造船、相机、电子和精密仪器能力迅速上升 |
| 军事 | 宪法限制下的自卫队体系，海外军事投送受限 |
| 南极公开活动 | 昭和基地1957年建立；日本南极考察在1962—65年中断，1964年没有正常运行的本国站网 |

日本接触白渊的材料来自战后接收档案、昭和基地早期样本和精密设备供应链。低温工程与医学资料由盟军筛选后分散进入大学和企业，部分纸张只保留日文设备名和测试温度。昭和基地在考察中断前送回的样本中，有几件被南极公约监督署重新编号，原始采集表仍留在日本机构。

1964年日本南极考察处在中断期，没有稳定的本国入口和常驻地下队。少量人员通过交换名额随美方或其他条约国行动，身份多为医生、摄影技术员、光学工程师和样本处理人员。现场所得材料回国后进入普通实验室，研究人员往往只知道样本需要低温、避光和双重封口。

日本卷宗对器材追踪尤其细。相机机身、镜头、快门维修、胶片批号、固定液配方和包装纸都有序列记录。一卷照片的技术来源因此容易查明，拍摄地点和档案内容仍可能被提供方删除。1962至1965年的公开考察中断也留下一道硬边界：任何写着日本常规站务的1964文件，都需要额外的交换任务或转存记录来解释。

## N10 智利

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 总统制共和国；豪尔赫·亚历山德里任至11月3日，爱德华多·弗雷·蒙塔尔瓦继任 |
| 政治 | 选举政治、土地与社会改革争论激烈，冷战影响加深 |
| 经济 | 铜矿出口居核心地位，通胀与结构改革压力并存 |
| 军事 | 军队在国内政治中有传统影响；海空力量熟悉南端与半岛通道 |
| 南极公开活动 | 设有阿图罗·普拉特与奥希金斯等站，重视南极主权和半岛通道 |

智利通过半岛站网、海军气象和伤员中转进入公约监督体系。阿图罗·普拉特与奥希金斯站提供近岸天气、船期、无线电和医疗接收，中央高原井线仍由其他国家掌握。地下行动人员返回半岛后，智利只处理转运和康复，通常看不到完整任务号。

智利和阿根廷对半岛许多地点使用各自的名称、坐标基准和主权表述。南极公约监督署建立了双名索引：原始文件保留本国名称，联合目录另挂坐标和来源。一次伤员转运可能在智利表格中写“自奥希金斯转出”，阿根廷材料则写“经埃斯佩兰萨接收”；船只换锚地、无线电转报和翻译习惯都可能产生这种差异。

1964年总统换届又改变了文件签署和追索方式。旧政府批准的海军附件进入新政府审查时，部分监督署编号被重新封存。智利卷宗对日期、邮戳、站名和坐标基准极为敏感，档案员会先还原跨国转运，再判断剩下的时间或人数差异。

## N11 比利时

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；国王博杜安，首相泰奥·勒费弗 |
| 政治 | 北约与欧洲共同体成员；刚经历刚果独立后的殖民体系震荡 |
| 经济 | 高度工业化，煤钢、制造和欧洲市场重要；地区与语言矛盾持续 |
| 军事 | 北约框架内的中等规模军队，南极工作以科学队为主 |
| 南极公开活动 | 博杜安王基地1958—61运行，1964年由比利时—荷兰联合队重建并进入第二个活动期 |

1964年比利时-荷兰联合队重新使用博杜安国王基地，地磁、冰川、气象和测绘记录恢复。基地没有连接白渊的下降井，人员通过北方委员会或南极公约监督署名额进入其他国家控制的入口。比利时测线覆盖的是地表和冰盖物理场，地下控制面积另按实际下降记录计算。

基地规模有限，连续记录反而容易保持原貌。雪尺、磁力仪、百叶箱和无线电值班表每天由少数人填写，换班与仪器故障都写在同一本日志。1964年一张比利时磁力曲线曾证明联合图幅的时间戳提前了十九小时，因为曲线上的磁扰与公开台站记录能够对应，而大国提交的图页使用了另一日天气。

联合队的资料分散在比利时、荷兰和承运机构。法语、荷兰语和英语版本对同一设备使用不同名称，原件归属也会随经费来源变化。比利时记录能够推翻一项时间判断，异常发生的原因仍留在未决栏。

## N12 法国

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 第五共和国；总统夏尔·戴高乐，总理乔治·蓬皮杜 |
| 政治 | 强调国家战略自主；1964年与中华人民共和国建交 |
| 经济 | 国家规划、工业现代化和消费增长并行 |
| 军事 | 独立核力量已经形成，仍在北约但保持自主路线 |
| 南极公开活动 | 迪蒙·迪维尔站自1956年运行；夏尔科内陆站1957年建立，1959/60前后关闭，1964年只能作为旧站 |

法国以迪蒙·迪维尔站维持公开海岸后勤，夏尔科旧站承担内陆缓存和路线遮蔽。人员从旧线转入夏尔科斜廊，抵达东部湖岸；奥尔菲探井只下放摄影、温度和取水设备。法方稳定直接探明约5.6万平方公里，其中约1.28万平方公里能够安排重复测线和有限驻留。

夏尔科站在1964年已经退出公开常驻使用。监督署小队使用旧建筑时，自带燃料、食品和无线电，不在公开站务表上建立完整越冬编制。旧站留下的雪埋房间、废弃油桶和早期测线为行动提供外壳，也使后来出现的维修单和气象页格外可疑。每一份1964年夏尔科记录都要能对应到临时任务、转存材料或后补誊件。

法国实验室保留自己的底片、分类卡和坐标基准。样本可以与美苏共享，命名意见和原始影像仍留在法方卷宗。分类学家会把俗名、临时属级判断和标本状态分开；纪录片人员则保存拍摄顺序和剪辑前素材。独立记录让法国在联合会议上经常提出异议，也给监督署档案留下第三套图名和编号。

## N13 澳大利亚

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；伊丽莎白二世为女王，罗伯特·孟席斯任总理；总督年内由德利尔子爵换为理查德·凯西 |
| 政治 | 西方联盟与英联邦成员，重视澳大利亚南极领地 |
| 经济 | 资源、农业出口、制造业和移民推动增长 |
| 军事 | 与英美安全体系紧密，具备南大洋海运和区域航空支持 |
| 南极公开活动 | 莫森1954、戴维斯1957；1959接管威尔克斯，1964年威尔克斯仍在使用但雪埋与结构问题严重 |

澳大利亚从戴维斯和莫森组织东部后勤，威尔克斯站保存旧美方建筑、箱号和维修资料。威尔克斯湿门所需的泵、潜水服、钢索、干燥箱和水样瓶主要由戴维斯线准备，再借路线杆和缓存点向入口转运。莫森承担远程无线电、地磁和图幅校准，通常不直接派车到湿门。

澳新联合测线稳定直接探明约4.5万平方公里，能定期复测和维持通道的区域约9600平方公里。澳大利亚记录以油桶编号、履带车里程、路线杆间距、雪埋深度和维修工时见长。湿门长期潮湿，绝缘、胶片、纸张和金属器材损坏率高，许多任务报告附有烘干时间和更换零件清单。

威尔克斯从美国转交澳大利亚后，同一座建筑保留美澳两套房号和维修编号。样本箱可能按美方旧房号入库，数年后又以澳方编号出现在清点表里。1964年卷宗仍使用Wilkes，Repstat和Casey属于1969年后的站史阶段。

## N14 瑞典

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；国王古斯塔夫六世·阿道夫，首相塔格·埃兰德 |
| 政治 | 军事不结盟，社会民主党长期执政，福利国家扩张 |
| 经济 | 高度工业化，机械、钢铁、通信、医药和精密仪器能力强 |
| 军事 | 保持独立国防工业和较强空军，不参加北约 |
| 南极公开活动 | 拥有挪英瑞联合考察传统；1964年通过合作项目和专业人员参与南极事务 |

瑞典在北方委员会中负责医学观察、测绳、仪器校准和盲样复核。参与现场任务的人员从南森门或塔巴林井下降，路线和样本归入委员会联合图，瑞典机构保留实验副本和设备记录。人数很少，岗位通常是医生、测量员或实验室技术员。

斯德哥尔摩收到的样本常被去除入口和国家信息，只保留采集时间、保存温度、固定液和容器号。实验员测量组织结构、盐分、蛋白条带或低温稳定性，再把原始表格和未拆封对照样一起退回。人员观察则保留体温曲线、反应时和睡眠记录，避免把同一次访谈反复誊成多个独立证词。

1963年的一次仪器复核暴露出校准链风险。三国测量结果高度一致，后来才发现共同使用的母仪器本身带有固定偏差。瑞典卷宗从此要求记录校准器序列号、校准日期和运输状态。表格整齐只能证明程序一致，测量基准仍要追溯。

## N15 美国

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 联邦总统制共和国；总统林登·B·约翰逊 |
| 政治 | 民权法案通过，总统大选，越南介入升级，冷战与太空竞赛持续 |
| 经济 | 全球最大的工业与消费经济，联邦科研、大学和承包商体系庞大 |
| 军事 | 全球投送、核三位一体、海空军与海军工程能力突出 |
| 南极公开活动 | 深冻行动建立长期后勤；麦克默多、南极点和伯德站构成海岸—内陆骨架 |

美国南极测绘局把白渊任务拆进公开科研和海军后勤。航空测绘、地磁、冰芯、胶片、大学合同、医疗和井线工程分别使用自己的预算与编号。雅各竖井和蓝阶斜道承担人员及重货，地平线通风井维持空气交换和紧急撤离，回声探井只投放仪器。地表航空和地球物理资料覆盖约227万平方公里，稳定直接探明约32.6万平方公里，能够维持巡线和设施的区域约11.5万平方公里。

资料分拆贯穿整套制度。大学实验室收到样本，却看不到坐标；海军掌握运输路线，却拿不到生物报告；承包商负责冲洗胶片，只以卷号识别人名。跨部门调阅需要项目原号、BAS归档号和监督署交换号同时闭合，缺少其中一个号码，档案员只能看到局部卷宗。局内没有任何办公室日常持有全部材料。

联邦政治通过授权和预算影响项目。总统或高级官员接触的是压缩简报、风险附件和经部门会签的选项，现场异常不会以神秘传闻直接进入白宫。1964年民权、大选、越南和太空项目争夺注意力与经费，BAS借普通合同维持白渊任务，也承受审计、人员轮换和责任转移带来的缺页。

## N16 苏联

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 苏维埃社会主义共和国联盟。赫鲁晓夫10月14日前任苏共中央第一书记和部长会议主席；此后勃列日涅夫任第一书记，柯西金任部长会议主席；国家元首职能由最高苏维埃主席团主席承担 |
| 政治 | 党国体制；赫鲁晓夫下台，中苏分裂，华约与美苏竞争持续 |
| 经济 | 计划经济、重工业、航天和军工强，消费与农业存在长期压力 |
| 军事 | 核超级大国，陆军、导弹和远程航空强；内陆履带运输与长期驻扎能力突出 |
| 南极公开活动 | 和平、东方、新拉扎列夫等站与长距离内陆路线已成体系 |

内陆特别作业局依托和平站至东方站的长距离运输体系。曙光一号货运井接收重型构件，红坡道承担车辆和人员，湖钟探口投放地球物理仪器，西线九号井在失联后仍占用地图编号和补给科目。苏方稳定直接探明约42.9万平方公里，能够维持设施、驻队和定期巡查的区域约17.3万平方公里。

苏联体系把行动写成命令、路线护照、班次和责任人。命令核准后，燃料、车辆、绞车和食品会按表抵达，即使命令依据的是一张错误地图。现场人员发现路线不存在时，也要逐级申请停工或改线。1964年的西线空地因此同时留下“工程已交付”和“现场从未施工”两套完整记录。

10月领导层更替打乱了责任链。赫鲁晓夫时期签署的特别命令进入复核，勃列日涅夫与柯西金体系重新分配签署、追责和销毁权限。部分干部希望封存旧线，工程部门则要求完成已列入计划的设施。政治压力通过印章、预算、运输和人事调动进入白渊现场。

## N17 英国

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 君主立宪制；伊丽莎白二世。亚历克·道格拉斯-休姆任首相至10月16日，哈罗德·威尔逊继任 |
| 政治 | 工党在大选后执政；去殖民化、英联邦关系和财政压力并存 |
| 经济 | 成熟工业经济但增长乏力，国际收支压力突出 |
| 军事 | 仍有核力量、海军与全球基地，但资源收缩 |
| 南极公开活动 | FIDS/BAS拥有长期半岛站网、无线电、测绘、地质和生物档案 |

英国南极调查局在1962年由FIDS更名而来，继承了半岛站网、无线电、测绘底稿和大量早期人员记录。哈雷湾站提供长波监听与时间基线，南森门和塔巴林吊舱井由北方委员会共同使用。委员会稳定直接探明约10.9万平方公里，英国掌握其中相当一部分原始材料，现场面积仍按联合任务登记。

英国卷宗的份量来自底稿和封存程序。台站电报码、野外笔记、胶片接触印样、地名卡和关闭站点的移交清单往往比后来的联合报告更早。英国档案员可以确认一份材料何时进入系统、由谁关闭、是否曾被重新定密。重货和深部工程仍依赖美国或其他伙伴，英国的优势集中在材料链与版本控制。

同期文件使用F站或阿根廷群岛站。1977年后的汇编索引增列“法拉第站”，原件标题与旧呼号不作追改。10月大选和政府更替带来经费审查，北方委员会的秘密任务继续分散在气象、测绘、地质和站务开支中。

## N18 阿根廷

| 字段 | 内容 |
|---|---|
| 政体与领导层 | 总统制共和国；总统阿图罗·翁贝托·伊利亚 |
| 政治 | 文官政府受军方牵制，庇隆主义政治力量仍被限制 |
| 经济 | 农牧出口与工业化并存，通胀和政治不稳定影响长期政策 |
| 军事 | 军方在国内政治中影响大；海军和空军熟悉南端与半岛补给 |
| 南极公开活动 | 奥卡达斯长期运行，埃斯佩兰萨等站支撑半岛存在与主权叙事 |

阿根廷通过奥卡达斯、埃斯佩兰萨及半岛运输接触白渊外围材料。气象、电报、邮政、工资和家属通知都由本国体系保存，中央高原入口由其他国家掌握。阿根廷人员参与监督署任务时，通常先在半岛站完成身份和医疗登记，再经联合航线转往内陆。

本国地名和主权文件在交换时保留原样。监督署目录用双名和坐标建立索引，不覆盖阿根廷站务记录。一份伤员电报可能只写西班牙语站名，英方转报使用另一名称；调查人员需要沿着电台呼号、日期和承运飞机核对，才能确定两份材料是否指向同一次转运。

阿根廷卷宗把地下事件带回普通行政生活。同一名队员可能同时留下抵站电报、工资、厨房配给和家属信，而监督署名册只记录他的地下代号。半岛站与中央入口相隔遥远，人员和样本必须经过飞机、船舶和中转站，每一段都产生自己的记录。政治不稳定和军方影响会改变档案开放程度，却不会抹去所有外围凭证。
