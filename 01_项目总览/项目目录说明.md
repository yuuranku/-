# 白渊项目目录说明

| 目录 | 内容 |
|---|---|
| `01_项目总览` | 项目整体设定与目录说明 |
| `02_世界观设定` | 世界规则、阵营、地理、时间线与附录 |
| `03_事件档案` | 已独立整理的具体事件与报告原件 |
| `04_任务档案` | 可直接交付或制作的任务素材包；当前包括 HZ-6 |
| `05_视觉素材` | 概念视觉、图像提示词与生成图片 |
| `06_创作参考` | 公文规范、现实校准、照片生成规范与资产索引 |
| `07_成品输出` | PDF 成品及透明视觉素材 |
| `08_工具脚本` | 生成与维护素材的脚本 |
| `09_临时工作文件` | 渲染检查图、中间文件与历史工作稿 |

任务编号、机构缩写、镜头编号等追溯信息保留在文件名中；其余目录均使用中文分类命名。
