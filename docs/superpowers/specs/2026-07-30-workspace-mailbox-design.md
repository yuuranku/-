# 工作台邮筒与审核提醒

## 目标

让书记官明确知道申请已投递、能收到管理员的实际批复；让管理员明确看到有待处理的档案申请。

## 入口

- 复用 `public/assets/icons/archive-inbox.svg`，在工作台桌面新增“邮筒”快捷方式。
- 书记官点击邮筒打开既有“审核回信”窗口。
- 管理员点击邮筒直接打开既有“审核与正式录入”队列。

## 状态与提醒

- 书记官提交成功后，提交状态明确显示“已投递至邮筒 / 等待审核”。
- 书记官存在未读审核通知时，邮筒快捷方式显示红色感叹号。
- 管理员的审核队列存在项目时，邮筒快捷方式显示红色感叹号。
- 书记官打开回信窗口后，将当前未读通知标记为已读并刷新徽记。

## 数据流

- 书记官提醒使用现有 `listNotifications(profile.id)` 与 `markNotificationRead`。
- 批复正文直接显示现有通知的 `message`、关联档案标题与创建时间。
- 管理员提醒使用现有 `listReviewQueue()`，不引入额外通知表或伪造状态。

## 边界

- 不改审核、发布和权限规则。
- 不改变现有桌面总体视觉，只增添一个与既有档案图标一致的邮筒快捷方式及小型状态徽记。
- 无服务连接或读取失败时，邮筒保持可打开，并在窗口中说明读取失败。
