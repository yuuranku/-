# 09 物种档案

## 分类说明

条目标题采用监督署生物分类组的暂定双名，供跨国样本检索和切片交换使用。问号表示证据不足，`incertae sedis`表示所属位置未定。同期实验记录采用形态、解剖、组织切片、染色体、培养、血清学、蛋白电泳和代谢试验；1977年后的测序材料另列复核卷。现场俗名只在采集经过中保留，不作为主索引。

## S01 Abyssodendron aciculatum

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida? → Streptophyta? → Tracheophyta样支系；种子植物关系未定 |
| 尺度 | 常高1—3米，少数约4米；主干直径4—16厘米；针叶3—8厘米 |
| 主要层 | 暮色针叶层，根系延伸至低林和旧骨层 |
| 标本状态 | 木质、针叶、根瘤、树脂和组织切片均有；无完整活株运出地表 |

采集记录中俗称“黑针木”。植株外形接近低矮针叶木，针叶排列、维管组织和根部结构与现生松柏类存在稳定差异。树皮黑灰，湿时有弱反光；枝条低而平展，长期朝向水气和暖岩，微光方向对枝条角度影响较小。根板宽，常与邻株及微生物膜连成片。

主要碳输入来自根部化能共生体，植株自身仍可能保留弱光合作用。树脂含铁、硫和复杂有机物，暴露空气后数分钟内变黏，气味接近湿木与矿物。生长环与地表年没有稳定对应关系，样本年代改用地层、沉积和交叉标记判断。

1964年报告分为`BIO-FL-01`形态测量、`ROOT-SYM/4`根瘤培养和`PROT-EL/12`蛋白电泳。分类组提出两种意见：高度变异的陆生维管植物，或与植物相似的独立真核支系。档案沿用黑针木这一野外名，正式科属栏保持空白。

## S02 Argenteofrutex glacialis

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida? → Streptophyta? → Tracheophyta样支系；与黑针木可能近缘 |
| 尺度 | 高1.5—4米，树皮薄片含硅质或盐类反光层 |
| 主要层 | 冰窗、暖湿谷和东部湖岸林缘 |
| 标本状态 | 树皮、叶片、幼根和少量完整幼株 |

采集记录中俗称“银皮冷杉”。银白外观来自表皮薄片对灯光的反射。叶片比黑针木宽，呈扁针或窄带状，背面有密集气孔样结构。折断后只有少量清汁，没有黑针木那种浓稠树脂。

它更依赖微光和稳定空气交换，可作为冰窗与通风的指示生物。强光会灼伤叶面，人工灯长期照射会让枝条偏向营地并改变样方。

1964年报告比较叶脉、气孔、木质部和蛋白条带。“冷杉”只保留为俗名，Pinaceae栏未填。法国样本与北方委员会样本尚未交换原切片，两批材料暂按同一形态组、不同采集群管理。

## S03 Hyalobryum recurvatum

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida? → Streptophyta? → Bryophyta样支系，亦可能是多生物共生薄层 |
| 尺度 | 单体不足5毫米，群落形成2—8毫米半透明薄片 |
| 主要层 | 冰顶滴水层、冰窗下缘和低林湿石 |
| 标本状态 | 干片、压片、培养瓶；离开高湿环境后多失活 |

采集记录中俗称“玻璃苔”。湿润时呈透明胶质叶片状，边缘可见细小绿色或灰蓝颗粒。受强光或干风后数十秒内卷成针状，复湿后部分恢复。侧光下能看见明显折射边缘，透明薄片在湿岩上仍可辨认。

它可能同时利用微光、溶解有机物和共生微生物产物。1964年可做显微切片、色素萃取、呼吸与弱光交换试验。若样本内出现多种细胞，不急于把整个薄片作为单一物种发表。

## S04 Ferrilichen rubrovenosus

| 字段 | 内容 |
|---|---|
| 现代临时分类 | 生态复合体：Fungi（Ascomycota?）+ 藻类／蓝细菌样共生体 |
| 尺度 | 壳状体厚0.2—3毫米，斑块直径数厘米至2米 |
| 主要层 | 暖岩、旧骨层表面和地热泥沼边缘 |
| 标本状态 | 岩片、菌丝切片、共生层分离培养均有，分离后多不生长 |

采集记录中俗称“红脉地衣”。暗灰壳体内有铁质红脉，地热脉冲或氧化条件变化时由暗红转黑。颜色变化需要数分钟至数小时，不像警示灯瞬间闪烁。

红脉由铁硫矿物和代谢产物共同沉积的可能性最高。1964年实验包括酸反应、显微结构、培养和铁含量测定。真菌样组织与共生细胞分别记录，整片复合体按地衣型群落归档。

## S05 Halorhizoma consortium

| 字段 | 内容 |
|---|---|
| 现代临时分类 | 多物种生态工程群落，不作为单一物种；包含根样真核生物、菌丝和细菌膜 |
| 尺度 | 厚5—35厘米，连续斑块可达数百平方米 |
| 主要层 | 盐地、暖泉和地热泥沼之间 |
| 标本状态 | 切块后结构迅速松散；只有分层样品和现场承重记录 |

采集记录中俗称“盐根毡”。表面像干硬纤维毡，能短时承载人员，底部却可能是温泥和水。群落会沿温度与化学梯度缓慢增生，旧边缘死亡、热源侧形成新层，因此几个月后看上去像“移动”。

固定桩、连续照片和干重测量显示，盐根毡通过热源侧增生、旧边缘死亡而缓慢改变边界。脚印只记录承重与表面状态。同期调查按群落剖面分别采集真核根样组织、菌丝和细菌膜，本卷以复合群落编号，分类栏标记“群落名”。

## S06 Cyanosporopteris ventosa

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida? → Streptophyta → Tracheophyta? → Polypodiopsida样支系 |
| 尺度 | 高20—70厘米，叶柄短，叶片厚而分叉 |
| 主要层 | 蕨状低林、地热沟边和通风路径 |
| 标本状态 | 孢子、叶片、地下茎和少量活体盆栽试验 |

采集记录中俗称“蓝孢蕨”。叶片灰绿或近黑，背面孢子囊成带状。孢子受紫外照射后呈冷蓝荧光，光源移除后随即消失。孢子细，容易随气流进入滤芯，野外队用沉降片推断通风方向。

地下茎与化能微生物共生，弱光会提高部分培养株的生长速度。1964年比较孢子形态、染色体计数、叶脉与组织切片。紫外照射会损伤样本，完成示踪后的样方另作受扰动标记，不再用于自然分布统计。

## S07 Leucocuticulata complex

| 字段 | 内容 |
|---|---|
| 现代临时分类 | 多类群俗称；主要为Animalia → Arthropoda，可能含Crustacea样与Hexapoda样支系 |
| 尺度 | 4—28毫米；个别“白壳”碎片可能来自更大型物种 |
| 主要层 | 冰壁甲壳带、根板、食物箱和空气滤芯 |
| 标本状态 | 完整个体、蜕壳、卵团和肠内容物均有；材料分属多个形态组 |

采集记录中俗称“白壳虫”。共同特征是浅色或半透明硬壳、低代谢，以及取食盐膜、菌膜和腐殖物。触角、足数、口器和鳃样结构差异很大。“白壳虫”作为野外集合名使用，标本按形态组另编子号。

它们会进入食物箱并堵塞滤芯，现有事故记录没有主动攻击人员的案例。1964年先按体节、附肢和口器分组，再进行蛋白电泳。HZ-6克莱恩采集的白壳碎片使用独立编号，只与同形态材料比较。

## S08 Argentichthys caecus

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Chordata? → Vertebrata? → Actinopterygii样支系，位置未定 |
| 尺度 | 常见12—45厘米，少数声呐目标更大但无标本 |
| 主要层 | 黑湖、暗河和湿门下游 |
| 标本状态 | 小型完整个体、鳞片样薄片、骨软骨组织和水下影像 |

采集记录中俗称“盲银鱼”。身体银灰、无可辨眼球，头部和体侧有密集压觉或电感受孔。鳍条、鳃和中轴骨骼与现代鱼类相似，但部分组织高度软骨化。离水后很快失去体形，早期照片常把塌陷标本拍得像带状软体动物。

它们沿水压、振动和电场变化活动，食物包括微生物膜、小型节肢动物和沉积有机物。1964年进行解剖、骨骼透明染色、血清蛋白和行为水槽试验。“银鱼”保留为外观俗名，正式鱼类科属栏保持未定。

## S09 Tacitornis tremulans

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Chordata? → Tetrapoda? → Aves?，低置信度 |
| 尺度 | 推定体长35—60厘米；完整尸体未入档 |
| 主要层 | 暮色针叶层、蓝冰穹边缘和高根板 |
| 标本状态 | 羽片样结构、脚印、粪粒、巢材和录音；无完整骨架 |

采集记录中俗称“静默鸟”。野外人员把它叫“鸟”，因为高处活动、留下三趾样痕迹和羽片。但现有材料不足以确认真正鸟类。它很少发出空气传播的鸣叫，重复敲击、低频振动和地面传导可能承担交流。

敲击停止常被队员当作大型动物接近的信号，但这只是经验相关。1964报告应记录频率、间隔、传播方向和地面类型。没有完整胸带、喙和羽毛微结构前，不写成“地下乌鸦”或固定鸟科。

## S10 Cervocinerus thermophilus

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Chordata → Vertebrata → Mammalia? → Eutheria? → Artiodactyla样支系 |
| 尺度 | 肩高约0.9—1.2米，估重45—85公斤 |
| 主要层 | 暮色针叶层、暖泉、盐地和低林过渡带 |
| 标本状态 | 足迹、毛、粪、啃食面、局部骨骼；无可靠完整成体 |

采集记录中俗称“灰鹿”。轮廓像小型鹿，皮毛灰而稀，耳大，眼反光弱。角是否存在未确认，部分“角”可能是根枝叠影。足端为分趾还是软垫仍有两套记录。

它以低密度小群或单体迁徙，取食根毡、孢子植物，也可能舔食盐壳和翻食小动物。1964可用牙齿磨耗、粪便、毛发和血清蛋白判断食性与亲缘。没有证据支持大群奔跑或每次任务都遇见。

## S11 Dendrotherium longirameum

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Chordata? → Tetrapoda?，纲与目未定 |
| 尺度 | 由脚印和局部照片推定体长2.2—3.4米、肩部约1.1—1.5米；误差很大 |
| 主要层 | 暮色针叶层、根板密集区和黑湖支流附近 |
| 标本状态 | 脚印、湿痕、倒伏根板、少量毛／表皮疑似物和HZ-6失败胶片；无完整组织 |

采集记录中俗称“长枝兽”，HZ-6卷内曾以接触对象号`HZ6-CO-01`登记。身体低伏、背部长、肩部抬高，前部肢体能跨压根板。闪光下某些姿势像“扶树”，但没有人手、脸或直立行走的可靠证据。

它对闪光、人员集结和逃跑节律有反应，捕食、领地、防御和受惊四种解释都留在分析栏。大型林下动物记录稀少，各起失踪事件分别调查。马洛里口述和胶片只支持1952年发生过一次近距接触，完整头部、肢端和体表仍无可靠材料。

1964年报告使用痕迹学、步距、受力、毛发显微和胶片测量。没有实体标本，名称承载模式和有效拉丁学名均未建立。档案中的“扶树”描述指一个模糊姿势，不构成人形结构证据。

## S12 Palaeobatrachomorpha lacustris

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Chordata? → Tetrapoda → Amphibia样或干群四足类，位置未定 |
| 尺度 | 25—110厘米，可能包含不止一个物种 |
| 主要层 | 湖岸、暗河、暖泥与季节水沟 |
| 标本状态 | 幼体、皮肤脱落物、卵胶、足迹和局部骨骼 |

采集记录中俗称“古两栖样动物”。体表湿润，四肢短，尾部发达；部分个体有外鳃样结构，另一些只有皮肤褶皱。对水体溶氧、盐度和硫化物变化敏感，常在水化学改变前迁离。

“古”来自骨骼外观。1964年比较椎骨、肢带、皮肤腺、卵和变态过程，尚未建立年代与系统发育位置。不同大小样本按采集点和形态分别编号，幼体、成体与多物种三种解释同时保留。

## S13 Hyalolepis filata

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Arthropoda → Hexapoda → Insecta? → Lepidoptera样支系 |
| 尺度 | 翼展4—12厘米 |
| 主要层 | 暖岩、设备间、低林和人工光源附近 |
| 标本状态 | 成虫、翅片、蛹壳和少量幼虫；鳞粉极少 |

采集记录中俗称“丝翼蛾”。翅面透明或半透明，几乎没有典型鳞粉，飞行时在定向灯下形成连续细线反光。它们常聚集在电台变压器和暖电缆附近，可能趋热、趋电场或取食凝结物，并不证明会“听懂无线电”。

1964可检查翅脉、口器、触角、变态和趋性。若缺少鳞片与典型口器，Lepidoptera只能保留问号。大量聚集可能堵塞散热孔，应先按设备风险处理。

## S14 Rhizocaris loricata

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Arthropoda → Myriapoda?／Crustacea?，位置未定 |
| 尺度 | 体长12—28厘米，多足；背负根皮后外形更大 |
| 主要层 | 根板、旧骨层和蕨状低林 |
| 标本状态 | 完整个体、蜕皮、背负根片和肠内容物 |

采集记录中俗称“根甲兽”。身体扁平分节，足多，背部有钩突，会把脱落根皮和矿壳固定在体表。静止时与根板纹理接近，受惊后钻入裂隙，不主动追逐人员。

背负行为可能用于伪装、保湿或培养食物膜。1964分类需看附肢是否分叉、呼吸结构和口器，才能判断更接近多足类还是甲壳类。中文“兽”只是俗称，不代表脊椎动物。

## S15 Cryovenia salina

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida? → Streptophyta? → Tracheophyta?；单子叶植物样支系 |
| 尺度 | 高8—25厘米，叶宽2—7毫米；地下茎沿盐水细沟延伸 |
| 主要层 | 冰顶滴水层下缘、低林冷水沟和黑湖季节岸线 |
| 标本状态 | 叶片、地下茎、根样组织和三个完整小株；未见花、种子或可靠孢子囊 |

采集记录中俗称“冰脉草”。叶片狭长，表面灰白，内部有深色纵脉。纵脉含铁硫颗粒和成束导管样组织，融水增多时颜色变深，水位退去后叶片从尖端开始卷曲。成片植株沿盐水细沟排成断续线，野外队常把它当作浅沟边界使用。

地下茎与冷水沉积中的微生物膜紧密相连，切断后叶片仍可维持数日，但碳交换迅速下降。1964年材料适合比较叶脉、导管、染色体和根部培养。现场没有观察到开花结构，“草”只描述株形，不填入禾本科。

## S16 Saccophonia ferrica

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota incertae sedis；固着多细胞囊状体，植物、真菌与独立真核支系三种意见并存 |
| 尺度 | 囊体高5—18厘米，口径1—6厘米；常由同一基部生出3—20个囊体 |
| 主要层 | 地热泥沼冷缘、暖岩裂缝和低风速的旧骨开挖面 |
| 标本状态 | 固定囊体、基部薄片、腔内液和两组短期培养；离开原基质后全部塌陷 |

采集记录中俗称“铁铃囊”。成熟囊体像薄壁小杯，外表黑褐，内壁沉积铁质亮点。气压或地热蒸汽流量改变时，囊口会缓慢收紧，邻近囊体因此发出高低不同的空腔共振。声音可持续数分钟，来源是气流与囊壁张力，不按呼叫、脚步或无线电节律重复。

基部没有典型根，却与矿物膜和细菌层形成连续界面。1964年报告登记囊壁细胞、腔液离子、压力响应和分离培养，不能仅凭固着生长把它列入植物。密集群落会积存二氧化碳，取样前先抽取囊腔气体。

## S17 Bathyanguilla pectinata

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Chordata? → Vertebrata?；无颌类或高度特化鱼形支系，位置未定 |
| 尺度 | 已测残体长46—83厘米；声呐推定成体可达1.6米，但无实体支持 |
| 主要层 | 黑湖化学跃层、深水岩缝和低氧暗河 |
| 标本状态 | 两段前体、一个尾端、黏液和六次水下影像；没有完整头部 |

采集记录中俗称“黑湖栉鳗”。身体细长，皮肤暗灰，无鳞。体侧排列数十条短而硬的梳齿状褶片，离水后贴伏在皮肤上，早期标本因此被误记为盲银鱼残体。现有前体材料没有可辨颌骨，口缘只保留环状软组织和角质小齿。

它活动在盲银鱼较少进入的低氧深层，可能刮食岩膜、腐肉或沉积表面的软体生物。1964年可比较中轴骨骼、鳃区、血清蛋白和耐低氧反应。声呐中的大型回波不并入体长统计，除非取得比例参照或实体材料。

## S18 Funambularachne longipes

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Arthropoda → Chelicerata? → Arachnida?；蛛形纲样支系 |
| 尺度 | 体长2—5厘米，展开足幅18—46厘米 |
| 主要层 | 暮色针叶层高根板、冰壁裂缝和废弃电缆沟 |
| 标本状态 | 四个完整个体、脱落附肢、卵囊样包被物和多处丝索；活体最多维持十一日 |

采集记录中俗称“索足蛛”。躯体很小，八条长足分节明显，末端有成对钩爪。它在裂隙和根板之间架设单根或双根粗丝，不结规则捕虫网；个体伏在丝索一端，通过振动接近落下的白壳虫和丝翼蛾幼体。

丝索含蛋白和矿物颗粒，强度高但在干燥空气中迅速脆裂。1964年分类需检查口器、呼吸器官、附肢分化和卵发育。营地电缆上的丝索先按设备污染处理，不能据此声称动物会辨认人工线路。

## S19 Osteopecten radulans

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Animalia → Bilateria? → Protostomia?；环节动物样与触手冠动物样特征并存 |
| 尺度 | 体长6—22厘米，前端篦状冠展开宽3—12厘米 |
| 主要层 | 根板与旧骨层、黑湖岸边骨堆和低速渗水面 |
| 标本状态 | 完整个体、收缩标本、消化物和附着管；软体固定后变形明显 |

采集记录中俗称“骨篦虫”。身体乳灰、柔软分节，后端固定在骨缝或木质根板中。前端展开两列篦齿状软突，水膜经过时刮取矿物膜、细菌团和细碎有机物；受到脚步振动后，软突会依次收回，数秒后只剩一条不起眼的附着管。

它参与旧骨层表面的物质再循环，密集处会把骨面清理成平行细纹。1964年记录分节、刚毛、消化道和幼体形态，并比较不同基质上的附着管。骨面条纹不能单独作为本种痕迹，工具刮擦和根系磨损必须先排除。

## S20 Ferriphyllum candelabrum

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida?；叶状体植物样支系，与红藻及陆生植物关系均未定 |
| 尺度 | 主体高12—38厘米，分枝宽可达45厘米；叶状片厚1—4毫米 |
| 主要层 | 地热泥沼冷缘、暖岩台和黑针木林中的低温蒸汽裂缝 |
| 标本状态 | 叶状片、附着盘、分枝顶端和两株连基质标本；培养三周后停止生长 |

采集记录中俗称“铁烛叶”。主体从扁平附着盘向上分出数层叉枝，灯光下边缘呈铜红反射，远看像一排低矮烛焰。反光来自叶状片内排列的铁质颗粒，本身不发光；熄灯后的长曝光没有记录到持续光源。

附着盘下方与硫氧化微生物膜相连，叶状片则含少量可萃取色素。1964年报告比较分枝方式、细胞分层、色素和暗处气体交换。长期照明会改变反射角和含水量，不能用营地周围的弯曲方向推断自然趋光。

## S21 Nebulorhiza condensata

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota incertae sedis；丝状多细胞拟植物，可能与玻璃苔所属复合群近缘 |
| 尺度 | 单丝直径0.3—1.2毫米，垂挂长度15—90厘米；成片覆盖数平方米 |
| 主要层 | 冰顶滴水层、通风裂口下方和高湿岩檐 |
| 标本状态 | 湿态丝束、附着端、凝结水和短期封闭培养；干燥样全部断裂 |

采集记录中俗称“雾根草”。灰白丝束从岩檐向下垂挂，表面持续凝结细小水珠，远看像悬在半空的根。丝束没有可辨维管束，附着端也不伸入岩体；水珠会沿表面微沟缓慢汇入下方菌膜和薄土。

它可能依靠凝结水中的溶解物、共生细胞产物和极弱散射光维持代谢。1964年记录细胞连续性、附着端结构、吸水速度和弱光交换。人员经过造成的气流会让整片丝束偏转，方向资料必须与无人员时的定时摄影对照。

## S22 Nivellophyton lamellatum

| 字段 | 内容 |
|---|---|
| 现代临时分类 | Eukaryota → Archaeplastida? → Streptophyta?；扁平轴拟植物，维管组织未确认 |
| 尺度 | 单片长6—24厘米、宽1—5厘米；层叠群落厚可达18厘米 |
| 主要层 | 冰壁甲壳带下缘、冷水渗面和蕨状低林背阴侧 |
| 标本状态 | 完整叶状片、基部切片、表面孢粒样结构和四处固定样方 |

采集记录中俗称“雪幕叶”。乳白叶状片从同一基部水平伸出，层层覆盖，边缘始终朝向水膜来向。新片半透明，老片积存矿物后变成灰白硬层；折断面可见重复隔膜，却没有确定的叶脉。

群落会截留滴水中的矿粉和白壳虫蜕片，为冰壁下方形成窄小沉积台。1964年工作包括隔膜切片、表面孢粒培养、灰分和碳交换测量。硬化老片可能只是死亡组织，不能把整层厚度当作单株年龄。

## 物种报告最低附件

完整物种卷包括比例尺照片或绘图、采集位置与生态层、样本编号、固定方法、形态测量、1964年实验、危险性和分类置信度。缺少完整标本的条目标为“痕迹分类”；复原图在图注中明确标记为复原。

## 分类置信度

| 级别 | 条件 |
|---|---|
| A | 有多个完整标本、解剖与可重复实验 |
| B | 有局部标本和多地痕迹，可确定高层类群 |
| C | 只有碎片、照片或单地点样本，分类开放 |
| D | 只有口述、脚印或不稳定影像，只保留野外俗名 |

当前建议：白壳虫、盐根毡按“群落／统称”管理；黑针木、银皮冷杉、蓝孢蕨、冰脉草、铁烛叶与雪幕叶为B—C；铁铃囊与雾根草为C；盲银鱼、古两栖样动物、索足蛛与骨篦虫为B；黑湖栉鳗与静默鸟为C；灰鹿为C；长枝兽为D。
