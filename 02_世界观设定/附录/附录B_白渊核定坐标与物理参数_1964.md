### B.1.1 地表投影控制顶点

以下坐标按边界顺时针记录，格式为“经度、纬度”（EPSG:4326）：

`(35°E,75°S) → (75°E,74°S) → (115°E,75°S) → (140°E,77°30′S) → (145°E,81°30′S) → (130°E,85°30′S) → (85°E,88°12′S) → (35°E,87°S) → (10°E,83°S) → (10°E,78°S) → (22°E,76°S)`

以南极点为中心的兰伯特方位等积近似计算面积为276.9万平方公里，正式文本圆整为277万平方公里。该边界是架空设定中的1964核定线，不应被理解为现实地质边界。

## B.5 视觉硬规则

- 白渊不是一座单体巨洞；远景必须允许岩脊、雾和分隔盆地存在。
- 大型林区以岩顶承重，冰顶只在局部跨空。
- 黑针木通常1—3米，少数4米；树梢不得触碰冰顶。
- 普通林区接近全暗，所有档案照需要人造光、慢门或闪光支持。
- 地面以裸岩、黑泥、薄霜、浅水和根板为主，不是厚雪森林。
- 大型动物极少，不能在每次野外任务中出现。

## B.6 地图使用规则

1. 现有南极范围图中的点状边界代表地表物理投影区，不代表白渊内部展开面积。
2. 事件地图应再标明“可步行”“可通车”“水文相连”或“仅地震推测”。
3. 地下路线不得直接按地表直线距离计算。
4. 各国图幅允许2—15公里正常投影差；15公里以上才进入异常复核。
5. 未标注测绘年份、来源机构和路线类型的白渊地图不能作为正式行动母图。

## B.7 超自然参数边界

| 项目 | 核定口径 |
|---|---|
| 未核算代谢余量 | 已知物理机制约能解释60%—80%的宏观生物量；余量不可稳定取能 |
| 常规图幅差 | 2—15公里，先按测绘问题处理 |
| 异常稳定偏差 | 常见15—80公里，必须有两条以上独立证据链 |
| 空间实体化 | 使用当地树木、岩土、水和既有构件；不凭空生成完整工业品 |
| 触发锚点 | 正式命名、路线编号、重复点名、验收、样本与长期行动 |
| 媒介规则 | 单件完成媒介保持稳定；不同版本互斥 |
| 意向性 | 可以表现方向性响应，不确认存在可交流人格 |
| 代价 | 新版本获得完整性时，其他路线、物资、身份或生态通常出现缺口 |

## B.8 拓扑深度速查

| 层级 | 距可靠锚点 | 典型空间倍率 | 行动许可 |
|---|---:|---:|---|
| L0 | 0—25公里 | 0.95—1.10倍 | 常规站务与运输 |
| L1 | 25—80公里 | 1.0—1.3倍 | 常规野外队，需路线杆 |
| L2 | 80—180公里 | 1.2—2.0倍 | 专门测绘队与双重返程方案 |
| L3 | 180—350公里 | 2—5倍 | 跨国批准、独立时钟与多套名册 |
| L4 | >350公里或锚点失联 | 无法核定 | 不作为常规救援承诺范围 |
