# 02 历史分歧与1964年时间线

## 2.1 为什么故事停在1964年

1964年前后，胶片、磁带、短波广播、手写日志和跨国档案仍然有足够迟滞。政府能剪辑新闻、重排名单、拖延家属通知，却还不能像后来那样快速统一所有版本。

## 2.2 时间线骨架

| 年份 | 公开世界与白渊秘密史 |
|---|---|
| 1921 | 国联南极开发署成立，公开汇总捕鲸航路、气象、地名和资源调查，秘密保存成员国提交的异常航片与远征事故卷。 |
| 1938-1939 | 德国南极考察以捕鲸、航空测绘和资源调查为名活动；德方取得异常航测、磁测和矿物记录。 |
| 1942-1944 | 美苏在极区冻土、寒区燃料和工程保障上投入战时研究；热钻、低温套管、远程供电进入军工系统。 |
| 1945 | 战争结束，德国和日本技术资料被战胜国分割；美苏接收热钻、南极、寒区矿业、低温医学和冻土工程资料。 |
| 1946 | 国联停止运作；国联南极开发署的人员、地图、缩微卷和未结事故移交新设的联合国南极管理局。 |
| 1949 | 联合钻探沿旧测线穿透冰盖，取回活体针叶组织，项目内部首次使用“白渊”一词。 |
| 1958 | 中苏联合队在北部林区失踪，两国人员表、遗物和无线电记录无法对上。 |
| 1959 | 南极条约公开签署；联合国南极管理局与核心参与国拟定秘密的《南极公约监督议定书》。 |
| 1961 | 条约生效；管理局将国联遗档部门与事故办公室改组为南极公约监督署，“归队矛盾”开始影响救援资格。 |
| 1962 | 核危机期间民用频段出现多语种南极人员确认广播。 |
| 1963 | 黑湖样本导致医院病历与血型档案互斥，出现“南极回返者健康恐慌”。 |
| 1964 | 西部林区出现与多国未实施交通计划重合的笔直空地，多国联合调查队即将出发。 |

详细时间线后续可从 v2.2 文档逐条迁入。
