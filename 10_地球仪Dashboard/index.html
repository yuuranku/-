        PALIS / ASSISTANT FILE 01

        关于白幕的创作细则

        概览

        理论上来说白幕是一个在南极之下的一片盆地，他由多个未知的生态系统组成。

        它的空间形态拥有：

        不稳定性，如：测绘地图于实际地图不符或偏差。

        未知性，广大白区域没有被测绘和收录。

        超自然性，有科学无法解释的怪异情况。

        此处的创作类似于后室，scp基金会之流。这是一片开放创作的空间。

        关于核心异常

        “闭合失效” 指：原本应该形成完整闭环、严密封闭或顺利合拢的结构/过程，没有达到预期状态。

        同一件事在档案中由不同分属的书记官记录会呈现出不同形式的报告文件。但最后只会输出一份报告结果。

        如：美国行动小队记录本小队行动五人，苏方轮值书记员出于某些原因记录本次行动四人。行动报告与记录报告都拥有实际影响认知的能力。最终的结算报告中就会出现五人与四人的“闭合失效”报告。如果四人的记录报告被白幕认定为标准报告，大部分人的认知将受到影响，白幕内部会如同愈合伤口一样将多的人存在记录抹除。且只有最终报告中会存在行动报告内容，且官方以最终报告为归档文档。

        回返者观察组就是由小部分没有完全被白幕认知覆盖的人组成，他们无法解释自己的“既视感” 医学上认为是“记忆错构”，某些人存在，或者某些事实实际不符，所以开始质疑官方档案，自己寻求事情的真相，但也深陷对自己的“既视感”的怀疑。

        对于事件：额外补充，事件拥有因果的锚点，由母本确定的结果将作为锚点无法改动。

        关于创作视角

        创作者书记官视角为准。他们负责在PALIS南极作业管理系统中记录与管理档案。不同书记官可以对同一事件或物种，科考站，生态，异常进行独立记录，书记官的权限非常开放，他们甚至可以引用旧有事件来对自己不完全了解的记录进行推导，甚至编造证据来为自己的记录佐证。最后由集体意识决定其母本与最终报告记录。以文本或以视频报告。

        所以再进入企划前，应对书记官进行设定。确定自己的立场与国籍；风格与性格。一旦确认，不应该轻易改动自己的立场。

        关于流程

        建立书记官档案→录入系统→开始进行相关内容填充→审核内容→内容录入系统→以第一版为母本→一个内容有多个版本→进行归档文档整理

        PALIS / ASSISTANT FILE 04 · HISTORICAL INGRESS

        世界观导入

        1. 1921年

          国联南极开发署成立，公开汇总捕鲸航路、气象、地名和资源调查，秘密保存成员国提交的异常航片与远征事故卷。

        2. 1938年

          德国南极考察以捕鲸、航空测绘和资源调查为名活动；德方取得异常航测、磁测和矿物记录。

        3. 1942–1944年

          美苏在极区冻土、寒区燃料和工程保障上投入战时研究；热钻、低温套管、远程供电进入军工系统。

        4. 1945年

          战争结束，德国和日本技术资料被战胜国分割；美苏接收热钻、南极、寒区矿业、低温医学和冻土工程资。

        5. 1946年

          国联停止运作；国联南极开发署的人员、地图、卷宗移交新设的联合国南极管理局。各南极开发边缘签约。

        6. 1949年

          联合钻探沿旧测线穿透冰盖，取回活体针叶组织，项目内部首次使用“白幕”一词。

        7. 1952–1955年

          国际地球物理年组织开始邀请中国科学院参与。中国科学院决定参加，成立国家委员会，准备气象、地磁、经纬度、地震、高空观测等项目，并通过苏联渠道取得仪器、资料和训练机会。

        8. 1958年

          中苏联合勘探队在北部林区将第一次超自然异常在苏联档案中被记录。中方海燕小队在苏方失误失踪。中苏交恶。中方在非《南极公约》体系建立海燕中转站并启动昆仑工程独自研究“白幕”。

        9. 1959年

          南极条约公开签署，视为第二次南极条约；联合国南极管理局与核心参与国拟定秘密的《南极公约监督议定书》。

        10. 1961年

          条约生效；南极管理局将国联遗档部门与事故办公室改组为南极公约监管办公室，PALIS南极作业管理系统接入各缔约国相关系统。
