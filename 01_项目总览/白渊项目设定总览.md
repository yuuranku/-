## 2. 美国机构统一命名

后续美国线统一使用：

**美国南极测绘局**  
**Bureau of Antarctic Survey**  
缩写：**BAS**

旧名 **美国极地边疆局 / Polar Frontier Bureau / PFB** 停用。后续新文本、事件报告、照片归档、美国阵营设定均改用 BAS。

### 2.1 BAS 的定位

美国南极测绘局不是公开意义上的独立情报机构，而是一个挂靠在南极科研、海军后勤、地球物理测绘和冰芯项目之间的行政机构。它的名字听起来应该很普通，甚至有些无聊。

公开职责：
- 南极中央高原测绘
- 冰盖航测、磁测与地球物理资料整理
- 内陆站点坐标、路线和航线图幅维护
- 科考队野外摄影、胶片、样本和事故资料归档

秘密职责：
- 管理美国进入白渊的井线、林下站和样本线
- 处理照片、胶片、地图与人员清点中的互斥证据
- 维持美国版本的白渊地理叙事
- 在南极公约监督议定书框架下和其他国家交换最低限度资料

组织性格：
美国线的恐怖不应来自“神秘局长”或单一阴谋，而来自项目、合同、胶片、地图、承包商、海军后勤和可否认文件把真相拆散。BAS 的错误通常是资料太多、版本太多、责任链太长。

### 2.2 BAS 文件格式示例

```text
BAS FIELD INCIDENT REPORT HZ-6-61
Bureau of Antarctic Survey
Horizon Station Field Office
McMurdo Records Copy
Classification: BAS INTERNAL / ACOA REVIEW
```

中文可写作：

```text
美国南极测绘局野外事故报告 HZ-6-61
地平线站野外办公室
麦克默多归档副本
密级：BAS内部 / 监督署复核
```

## 3. 白渊核心设定

白渊位于东南极洲中央高原下方、南极点—甘布尔采夫冰下山脉—东方站之间，是一组被冰盖埋藏的岩盆、断裂谷、冰岩交界空间、地下水系和低生产力生态层。名义中心为81°46′S、75°09′E。地图上的约277万平方公里虚线区是1964年联合航空地球物理资料初定、后来由卫星遥感确认的地表物理投影；白渊内部存在多张互斥空间页，1964年展开面积下限约720万平方公里，工作估计约960万—1500万平方公里。越远离入口、站点、路线杆和有线中继，空间倍率与路线错乱越严重。白渊不是一口垂直无底洞，也不是整片冰盖下的普通空洞。

核心气质：
- 架空二战后至冷战早期
- 模拟恐怖与档案恐怖
- 南极科研、军方后勤、胶片、无线电、地图和行政流程
- 国家不是“人格化角色”，而是组织性格被白渊反映和放大
- 异常不直接操控世界，而是让记录、人员、地图、身份和归队流程无法闭合

主线年份：**1964**

前史：
- 1938-1939：德国南极航测、磁测、矿物资料留下异常线索
- 1942-1944：美苏以寒区燃料、热钻、冻土工程和极区储备为名推进相关技术
- 1945：德国和日本资料被战胜国拆分接收
- 1949：沿旧测线重新钻进中央冰盖，首次取回活体针叶组织，内部开始使用“白渊”一词

## 4. 白渊生态方向

白渊生态不是菌类生态，也不是现代森林。它是一套以铁、硫、氮、氢和甲烷循环的化能微生物为底座、由低生产力拟植物和稀疏大型动物构成的原始旁支生态。微光只负责可见性，不能解释主要能量来源。

主要生态层：
- 冰顶滴水层
- 冰壁甲壳带
- 蕨状低林层
- 暮色针叶层
- 黑湖水系
- 地热泥沼
- 根板与旧骨沉积层

可用生物：
- 黑针木
- 银皮冷杉
- 灰鹿
- 静默鸟
- 长枝兽
- 盲银鱼
- 白壳虫
- 古两栖样动物

写作原则：
不要把白渊写成怪物图鉴。生态越复杂，异常越应该通过样本、气味、滤芯、胶片、尸检、脚印和迁徙痕迹进入故事。

## 5. 异常规则

核心工作用语：**闭合失败**

白渊异常不是万能现实改写。它更像让组织流程、记录系统和人员认领产生稳定但互斥的版本。

白渊允许真实超自然存在：空间可能记住未实施的路线，生态可能保留点名与行动节律，已知热流和化学能也只能解释约60%—80%的宏观生物量。未能核算的部分正式称为“未核算代谢余量”，简称“白余量”。它依赖名称、编号、路线、样本和重复行动等锚点，优先重排已有物质与信息，不能作为无限能源或任意魔法使用。

可用异常：
- 人数不闭合
- 行程缺段
- 归队矛盾
- 证据互斥
- 职位错置
- 地理闭合失败
- 人员重叠
- 国家组织性格回响
- 元首记忆回响
- 生态反馈

边界：
- 不让全球历史随意改写
- 不让国家元首被公开附身
- 不让录像或胶片实时变化
- 不让每次事故都归因于超自然
- 每份实体媒介本身应稳定，恐怖来自不同媒介之间的稳定矛盾

## 6. 主要阵营

| 阵营 | 当前定位 |
|---|---|
| 美国：美国南极测绘局 BAS | 航测、胶片、无线电监听、地图、后勤和可否认资料 |
| 苏联：内陆特别作业局 | 永久驻扎、重型工程、命令链、地下长期生存 |
| 中国：昆仑工程 | 先通过中苏合作接触白渊，1958年事故后转向独立证据链 |
| 北方联合考察委员会 | 英国、挪威、瑞典、丹麦等，掌握1949-1953原始胶片和私人日记 |
| 联合国南极管理局（UNAA） | 1946年接收国联南极开发署遗档；负责南极事务的预算、任命和政治协调 |
| 南极公约监督署（ACOA） | 联合国南极管理局下属执行机构；负责事故调停、人员交换、跨国档案比对和版本复核 |
| 次级组织 | 非结盟极地科学团、赫利俄斯工业联合体、回返者观察组 |

南极公约监督署的制度前身是1921年成立的国联南极开发署。国联停止运作后，原署的人员与档案于1946年转入联合国南极管理局；《南极条约》生效后，管理局在1961年将遗档部门与事故办公室改组为南极公约监督署。PALIS是监督署使用的联合档案系统，不是独立组织。

## 7. 1964 年主线事件

暂名：**西线归队事件**

1963年，一支苏联队伍在西部林区失踪。数周后，美方监听到他们的常规汇报：没有求救，没有惊慌，只反复说明队伍正沿一条废弃交通线前进，并称“全员已经归队”。苏联否认这支队伍存在。

1964年，美国雷达在针叶林上方发现一条长约四十公里的笔直空地。白渊从未确认修过铁路，但美、苏、中及北方委员会都保存过不同年代的交通线计划。路线方向和编号不一致，只有一小段投影重合。现场土层、倒木和根板证明空地是真实地貌，却找不到施工器材；它被南极公约监督署列为“空间记忆”的首个大型联合验证对象。

核心阶段：
1. 地表集结
2. 进入西线
3. 找到苏联营地
4. 归队记录出现
5. 人员重叠

## 8. 已写事件：HZ-6样本线任务记录

英文档案抬头：**BAS FIELD RECORD HZ-6-61**

当前推荐归档名：

```text
BAS FIELD RECORD HZ-6-61
Record Name: HZ-6 Sample Line Field Record
Date: November 18-19, 1961
Location: HZ-6 Sample Line, conifer layer, 8.7 miles southeast of Horizon Station
Filed By: Bureau of Antarctic Survey, Horizon Station Field Office
```

中文归档名：**HZ-6样本线任务记录**

核心内容：
美国南极测绘局一支四人科考小队在白渊暮色针叶层执行常规生态采样。随队摄影师托马斯·E·马洛里携带 Nikon F 35mm 单反和 Rolleiflex 3.5E 双反相机。小队在 HZ-6 样本线遭遇未分类林下动物，复核阶段临时编号为 **HZ6-CO-01**。摄影师幸存，但无法稳定描述接触对象。相机和胶卷在救援后被没收，冲洗出的照片进入限制档案。幸存者未被允许查看底片。

要点：
- 胶片相机无法即时确认画面，但摄影师知道自己是否按过快门、是否过片、闪光灯是否触发
- 真正不确定的是曝光、焦点、胶卷是否撕裂、画面里是否拍到目标
- 幸存者不能说“我拍到了”，更自然的说法是“先别动相机。胶卷还在里面。”
- “HZ-6/R06”是 BAS 影像室给 Nikon 内35毫米胶片追加的归档卷号，不是幸存者口述，也不是事件名
- 生物应更接近大型林下动物：低身、长背、肩部高，对闪光和人员集结有反应。可以有一点像人的错觉，例如前肢扶树，但不能让“像人”成为重点
- BAS 内部不得允许幸存者根据限制级摄影序列重建记忆

## 10. 老照片素材方向

当前已有 10 张照片概念：
1. 1947 年南极钻探站外景
2. 1952 年冰下原始生态首次记录
3. 1956 年冰下动物接触糊片
4. 1959 年原始节肢动物标本
5. 1961 年失踪队员最后一张
6. 1953 年无线电室记忆错乱
7. 1960 年站点合影人员重叠
8. 1962 年基地撤离公共危机
9. 1958 年冰壁中的站点重叠影像
10. 1964 年冰下动物迁徙车载失败照

照片文字风格：
英文短自述，不解释过满，像照片本身补一句证词。

例：

```text
I was not meant to be clear. Someone turned, someone shouted, and whatever crossed the water left only a wet line where a body should have been.
```

## 11. 圣经典故命名方向

这些典故不应变成宗教设定本身，而应像冷战机构给不可理解之物套上的古老名字。

| 名称 | 用法 |
|---|---|
| Good Shepherd Protocol | 队伍归属与身份确认流程 |
| Shepherd Clause | 队长或负责人必须为无法闭合名单承担责任 |
| The Fold Test | 判断某人是否属于本队/本国 |
| Lazarus Return | 失踪或死亡队伍被记录为已返回 |
| Babel Roll Call | 多语种点名广播人数、站名不一致 |
| Jacob Shaft | 地表通往冰下的主井或斜井 |
| Cold Manna | 无人申请却出现的补给 |
| Thomas Review | 用伤疤、指纹、血型确认重叠人员 |
| Empty Tomb Procedure | 尸体、死亡证明与本人存在无法闭合 |
| Ark Manifest | 撤离名单、样本、尸袋和座位数互相冲突 |

《约翰福音》10:11、10:14 的白渊解释：
“牧人认识自己的羊”在白渊中变成身份与归属的审判。队长、站长、监察员、国家项目负责人都必须知道谁属于自己。一旦白渊破坏“认识”，牺牲就会变成行政动作。

## 12. 领导人影响方向

白渊可以影响国家机器的正式记忆，但必须隐形。

可写方式：
- 国家元首误记一次不存在的南极简报
- 内阁或政治局把南极事故错误并入核试、边境危机或公共卫生议题
- 总参谋部重复签署一份附件
- 新闻稿和演讲使用同一套含混词汇，让错误版本获得国家背书

不能写成：
- 公开附身
- 直接控制人格
- 没有档案链的凭空命令
- 让所有人同时相信同一个谎言

## 13. 后续待统一事项

1. 正式设定集 v2.2 中如仍出现“美国极地边疆局 / PFB”，后续修订版应统一替换为“美国南极测绘局 / BAS”。
2. HZ-6样本线任务记录后续文本应使用 BAS，不再使用 PFB。
3. 美国线文件格式应更像测绘、航测、胶片和野外事故档案，而不是情报机构报告。
4. 新事件应尽量落到具体时间、设备型号、胶卷类型、物资清单、路线编号和归档流程上。
5. 视觉图中的文字和地图系统应避免过度现代化，优先使用老式测绘、航空图、井线编号和站点档案语言。
