# PALIS 极地档案联络与索引系统

## 正式名称

**PALIS**：**Polar Archive Liaison & Index System**，中文统一写作“极地档案联络与索引系统”。它是南极公约监督署用于接入、登记、比对和调阅跨国白渊档案的核心管理系统。网页与档案画面中的 `CHANNEL 09A` 是 PALIS 下的白渊联合记录频道。

PALIS 是系统，不是独立组织；它没有入口、人员主权或现场指挥权。对外出现时，应写作“南极公约监督署 PALIS 管理系统”或“PALIS／09A 联合档案频道”。

## 1964 年技术形态

PALIS 不是现代人工智能，也不会自动判断真假。1964 年的 PALIS 是一套分布式档案程序、编号规则和受控终端网络，由磁带库、穿孔卡、缩微胶片、行式打印机、电传线路和人工复核席共同组成。不同国家仍保管原件；PALIS 保存的是来源登记、索引副本、权限表、版本冲突和调阅轨迹。

终端能够执行的动作：

- 为文件、照片、坐标、人员和事件分配不可重复的联合索引号
- 记录原始保管机构、载体类型、抄录时间和经手人员
- 比对姓名、坐标、日期、任务编号和物资消耗等结构化字段
- 保留互斥版本，不以“较可信版本”覆盖其他版本
- 按国家、组织、任务和权限等级生成调阅目录
- 在每次调阅后留下纸带或行式打印记录

它不能执行的动作：

- 不能证明哪一份互斥档案是真相
- 不能把不同空间页强行合成一张可靠地图
- 不能绕过成员国的原件保管权与重型入口控制权
- 不能自行发布命令、修改归队状态或宣布人员死亡
- 不能删除冲突；删除只能表现为新的“撤销记录”

## 频道与状态

| 标识 | 含义 |
|---|---|
| `PALIS/64.11` | 1964 年 11 月核定的软件、编号表与人工流程版本 |
| `CHANNEL 09A` | 白渊入口、人员、事件和异常的联合记录频道 |
| `ARCHIVE HANDSHAKE` | 核对终端身份、权限表、索引版本和纸带序号 |
| `INDEX READY` | 目录可调阅，不代表内容真实或已经闭合 |
| `SOURCE CONFLICT` | 至少两份来源内部成立，但彼此不能同时为真 |
| `MANUAL REVIEW REQUIRED` | 自动字段比对已到达边界，必须交由南极公约监督署复核席处理 |

## 权限与人员

PALIS 的终端由南极公约监督署档案员、跨国联络员和版本复核员操作。各成员国可以看到与本国权限相符的联合索引，却不一定能调出别国原件。最高权限也只意味着“能看到冲突存在”，不意味着能看到冲突两边的全部内容。

任何人将 PALIS 的 `INDEX READY` 误读为“事实已经确认”，都可能把一个行政版本错误升级为跨国承认。这是系统最危险、也最常用的叙事矛盾。

## 与白渊异常的关系

PALIS 不会被白渊直接“感染成有意识的机器”。更合适的写法是：系统严格执行来源保留和编号规则后，仍会生成两个都合法的人员编号、两条都闭合的路线或两份都通过权限核验的归队记录。异常通过制度一致性显现，而不是通过电脑闹鬼显现。

## 视觉与文案规范

- PALIS 终端以黑白、1-bit／像素抖动和 Windows 98 式档案窗口表现。
- 强调色只使用冷战红、蓝；加载条使用单一深蓝色。
- 首页标准接入文案为：`正在接入 / PALIS 管理系统`。
- 上方机构小字统一为：`ANTARCTIC CONVENTION OVERSIGHT AUTHORITY · JOINT ARCHIVE CONTROL`。
- 接入状态统一为：`CHANNEL 09A / ARCHIVE HANDSHAKE`，完成后显示 `INDEX READY`。
- PALIS 的英文全名首次出现时写全；之后可只写 `PALIS` 或 `PALIS / 09A`。

## 写作边界

PALIS 适合反复出现在档案开场、调阅界面、人员核对、跨国争议和异常复核场景中。它的戏剧作用是保存矛盾、控制谁能看见矛盾，并留下行政痕迹；不要让它代替人物推理，也不要让它给出白渊的最终解释。
