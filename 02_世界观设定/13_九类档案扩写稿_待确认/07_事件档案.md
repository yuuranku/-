# 07 事件档案

本卷按事故调查次序保存初报、事实材料、分析意见和未决项。公开行动记录与限制卷材料使用不同来源号并在同一时间线上交叉核对；来源未核定的胶片只列附件号，不作为事故现场证据。

## V00 1938—39 德国南极考察／暗片带

| 字段 | 内容 |
|---|---|
| 公开行动记录 | 阿尔弗雷德·里彻尔率领的德国南极考察；施瓦本兰号、两架多尼尔“鲸”式水上飞机和航空摄影测量 |
| 记录日期 | 1939年2月3日，限制卷航次`Flug VII-B` |
| 记录地点 | 毛德皇后地内陆航测格网R-19/3 |
| 公开器材 | 两台Zeiss-Aerotopograph RMK C/1连续航摄相机；18×18厘米画幅；设计重叠率60% |
| 证据 | 左右胶片接触印样、领航图照片、暗房报告抄件、1944年清册、1946年美方格网覆写表 |
| 调查主卷 | `R-19/3-A` |

施瓦本兰号于1938年12月离开汉堡，次年1月抵达南极浮冰边缘。远征的公开目标由航测、气象、海洋学、地球物理与捕鲸资源调查共同组成，并服务于纳粹德国的经济和领土政策。船载水上飞机沿毛德皇后地海岸与内陆执行连续摄影，利用相邻画幅的重叠恢复地形。战争爆发后，原定后续考察停止，已经形成的航片、工作图和科学材料留在德国各机关中继续整理。

2月3日，“信风”号穿越R-19格网。右侧胶卷第421至427格拍到一条低反射谷地，左侧胶卷记录其外缘。胶片齿孔、边码和乳剂层连续，测试片与同批药液显影正常。摄影测量却无法闭合：同一谷内亮点在相邻画幅交换左右次序，左右相机的交会模型又把两台固定在同一机身上的相机解算到相距约四十公里。领航图在对应格网留下`Schattenfeld`，即“阴影区”。

船上制作了两套接触印样。航摄成果包保留一套，另一套与领航图、暗房记录和分开询问笔录装入灰色专卷。公开测线图把R-19/3处理为云遮空白；1942年成果卷的图版止于相邻地貌。战时机关迁移又将底片、印样和纸质记录分散到航空测绘与海军水文渠道。

1945年后，美、英、苏三方分别取得右卷印样与格网换算表、领航图照片与清册、左卷印样与转递单。美方在1946年把缴获格网覆写到跳高行动航空扇区图，R-19/3落入E-14复核区。1947年E-14再次取得低反射谷地航片，德国材料由敌国技术情报转入白渊前史卷。

暗片带记录限于空中观察、船上冲洗与欧洲境内的档案处理，六个飞行岗位均随飞机返船。1964年联合事件组仍缺右卷原底片、完整暗房报告和六张最初印样；现有副本足以确认格网、折痕、画幅与战后转递关系，谷地的现代坐标仍有百公里级误差。

## V01 1946—47 跳高行动／航片空白

| 字段 | 内容 |
|---|---|
| 公开行动记录 | 美国海军Operation Highjump，大规模舰船、航空训练与南极航测 |
| 记录日期 | 1947年2月11日为E-14返航计数事件；完整行动跨1946—47季 |
| 记录地点 | 罗斯海临时航空营地及中央高原航测扇区 |
| 目标 | 航空摄影、设备训练、冰况和基地行动；复核缴获的德国R-19格网 |
| 证据 | 航片、飞行日志、燃油、座位图、返航点名、相机故障单、1946年格网覆写表 |

1946年秋，美国海军测绘人员整理战败德国的航空测绘材料，把R-19工作格网换算为跳高行动使用的航图基准。三个德国坐标版本落在一片宽约一百八十公里的扇区内，行动图只将其标为E区摄影补缺，没有使用“阴影区”字样。E-14航次承担扇区南缘的斜向摄影，机组直到任务说明会结束也没有接触德国接触印样。

E-14返航胶片的一组相邻画幅出现黑色谷地。谷缘在四格底片中保持正常视差，谷内却缺少与航向相符的位移；云层、曝光和航线偏移都无法同时解释。胶片组把它列为相机故障，测绘组则发现谷缘轮廓与R-19右卷印样的三处山脊相合。两批照片相隔八年，使用的飞机、相机和坐标基准均不同。

返航点名引出第二条证据链。E-14按六人起飞，七人完成返航手续；燃油、口粮、救生装具和座位图仍只支持六人。第七名返航者持有当日口令，能说明机内器材位置，医务检查却找不到与个人装备对应的手套磨痕和低温暴露。两小时后的复点恢复为六人，第七份签名仍留在纸面，门岗和医务室各自保留一份闭合记录。

美方在1947年掌握了异常航片、人数冲突和一组来源于战败德国的测绘材料。伯德收到压缩摘要，并批准成立特殊校正席。该时期文件使用“黑区”“低反射谷地”和航片编号，1964年才形成的白渊术语尚未出现。R-19与E-14被分别封装，工作人员通过格网覆写表看到二者关联，原始胶片继续由不同部门保管。

E-14材料随后被拆入海军测绘、事故、医务和设备项目。胶片、光学相机记录、纸质航图、机械仪表与返航签名分在五条来源链中。1956年后，US-BAS沿旧卷号重新聚合材料；1964年联合事件组将德国暗片带列为最早航片异常，把E-14列为首次有人员计数冲突的复核行动。

## V02 1947—48 芬·龙尼私人远征／重复谷地

| 字段 | 内容 |
|---|---|
| 公开行动记录 | Ronne Antarctic Research Expedition，私人资助、航空摄影和半岛考察 |
| 记录地点 | 菲尔希纳冰架西缘的航测路径 |
| 目标 | 独立测绘与航空摄影 |
| 证据 | 私人航片、飞行本、底片边码、云层与太阳高度记录 |

两卷互不相邻航线的照片记录到与海军航片相似的黑色谷地边缘，连云层缺口都一致。私人来源使问题无法再被封成单次海军事故。

龙尼拥有原底片和远征飞行本，以私人远征负责人的身份与美国部门交涉。BAS前身取得部分复制件，龙尼仍保留原片及另一套接触印样。两条不相邻航线拍到相同谷地和云隙，争议集中在底片顺序、航线位置与重复景观之间的冲突。

英国、美国和龙尼私人档案各存一代复制件，裁切范围、纸张和背注各异。事件组用`Ronne-A`、`Ronne-B`、`Ronne-C`标记三条来源，所有摘录随卷登记复制代次。

## V03 1949 美苏联合钻探／样本拆分

| 字段 | 内容 |
|---|---|
| 卷宗状态 | 联合钻探限制卷；样本来源链待复核 |
| 地点 | 海湾中转站、中央冰盖旧测线和后续美苏实验室 |
| 目标 | 验证异常地震反射并取得深层冰／基岩样本 |
| 结果 | 取得仍有活性反应的针叶组织和含根丝沉积物 |
| 证据 | 钻探日志、两只样本箱、封条、称重、组织切片、培养失败记录 |

钻探使用窄孔取芯。探头依次穿过冰、裂隙和水气带，只带回少量针叶组织与含根丝沉积物。美苏交接时，两只样本箱同时拥有对方的封条、重量和签收记录，双方都找不到调包发生的环节。

美国把样本拆进海军、大学、地质与生物项目；苏联保留集中命令链，但把部分异常写成设备污染。没有实验室得到完整来源链。

“白渊”作为内部工作名从这批交接文件中出现。未决项集中在钻井位置、设备型号和美苏联合授权来源；三项均缺原始命令，只保留实验室入库记录和封条照片。

## V04 1952 HZ-6样本线任务

| 字段 | 内容 |
|---|---|
| 正式日期 | 1952年11月18—19日 |
| 任务编号 | HZ-6-52；事故胶卷号HZ-6/R06 |
| 地点 | 地平线站东南HZ-6样本线，暮色针叶层至黑湖支流 |
| 目标 | 根板、白壳碎片、空气滤芯与土样的常规复测 |
| 人员 | 拉斯克、克莱恩、基恩、马洛里、万斯，共五人 |
| 设备 | M29C Weasel、AN/PRC-10、Nikon S、Rolleiflex、Weston Master II、单次闪光灯泡、两支M1卡宾枪 |
| 调查主卷 | `HZ-6/R06` |

队伍按五人标准队形进入。1518克莱恩取下HZ-6C滤芯，1712光线和标灯同时减弱，1829前后发生未分类动物接触，队伍在返回HZ-6A前散开。马洛里于次日0218在路线以西约1.4英里处获救；拉斯克列死亡但遗体未回收，其余三人失踪。

证据链包括英文原件、中文译本、任务记录、无线电日志、Nikon胶卷、医务室笔录和未回收器材清单。马洛里记得按动快门、过片和闪光触发状态，对画面内容没有连续记忆。胶卷由US-BAS档案员和海军警卫接收，他没有参加冲洗，也没有看过底片。

主事故由动物接触、记忆缺段、人员失踪和胶片证据构成。A04“第六个回答与第六行”发生在1952年8月19日的前置巡线，参与者、录音和点名表另卷保存。11月五人任务沿用了前置巡线修订后的无线电中继与点名程序。

## V05 1953 无线电室双值班

| 字段 | 内容 |
|---|---|
| 性质 | 帕尔默地临时无线电设施事故 |
| 地点 | 帕尔默地临时中继室；与1965年建立的Palmer Station无关 |
| 证据 | 两套值班日志、咖啡配给、电报码、门锁记录、次日口述 |
| 异常 | 人员重叠／职位错置 |

一次定时通联后，同一房间留下两套完整夜班记录。两组值班员都能描述设备、故障和另一组从未进入过的房间。两份日志的电报码可分别通过校验，但发报时段重叠。

“帕尔默”来自帕尔默地的地理名称。中继室由一座季节性无线电棚和地下电缆间组成；美国正式使用Palmer Station这一站名是在此后。人员分开接受询问，门锁、杯具、咖啡配给、纸带和电报码全部封存。两套材料在封存后保持固定，后续争议来自它们同时通过时间与设备校验。

## V06 1955—56 深冻行动／常设后勤接入

| 字段 | 内容 |
|---|---|
| 公开行动记录 | Operation Deep Freeze I，基地、航空、海运和国际地球物理年准备 |
| 限制卷接入 | BAS从临时校正席转为跨机构限制级接口，K系入口开始常态化 |
| 证据 | 基地建设图、航线、货单、承包合同、海军命令与科学计划 |

麦克默多、南极点等公开设施使美国不需要另造一支秘密舰队。BAS把井线绞车、通风、胶片和样本冷链分散到公开项目中，地平线站也在这一阶段扩建。

这次行动在白渊档案中列为制度节点。海军负责建站与运输，科学机构申报冰芯、地震和通风项目，承包商交付绞车、胶片与冷藏箱。设备以不同合同进入南极，普通人员只看到自己负责的货物和工程段。

后果：白渊从少数航片问题变成可持续行动区，随之产生更多人员、预算和版本冲突。

## V07 1958 中苏联合队失踪

| 字段 | 内容 |
|---|---|
| 公开行动记录 | 国际地球物理年、苏联内陆远征、中苏科学资料合作 |
| 记录地点 | 东方站—海燕—昆仑一号旧井线及北部黑根林 |
| 目标 | 复测旧钻井、核对地磁与冰温、确认地下标记来源 |
| 证据 | 中苏两套派遣表、车辆和燃料、KL1换绳台记录、无线电、归队手续 |

联合队暂按八人编制：中方四人负责地磁、测绘、机电和医务，苏方四人负责冰川、钻井、无线电和路线安全。现存失踪卷只保留岗位号`C1—C4`、`S1—S4`；未在原始名册出现的公开考察人员不得补入名单。

1958年9月14日17时26分，队伍在第三换绳台以北失去常规联络。21时08分，八人从KL1内门返回，21时42分完成点名、初检和装备回收；最早原件是绞车值班簿夹着的中苏双语归队页。次日01时47分，D3仍收到同一队呼号请求换绳，搜救命令因此在归队手续完成约四小时后发出。近线搜索持续48小时，扩大搜索到第六日终止，没有找到第二支队伍或第三换绳台。

归队八人的身份、旧伤、个人物件和任务前口令都能核对，八台个人装备也已回收；但他们对17时26分之后没有连续记忆。与此同时，远端无线电的电池耗用时长超过原配电池理论值。中苏两方对派遣人数和第三换绳台是否存在仍无法闭合。

该事故促使昆仑工程改用实物留样、手绘地图和分开复述。苏联则强化路线护照和命令统一。双方没有谁天然更接近真相，只是保存了不同错误形态。

八人的个人卷仍以岗位号封存。现行名册固定人数、日期、首份归队记录和搜救时长，姓名栏留空；未列入限制任务的中苏科学人员没有并入失踪名单。

## V08 1962 基地紧急转移／两份名单

| 字段 | 内容 |
|---|---|
| 当前异常条目 | 1962年7月2日“哈雷撤离双清单” |
| 性质 | 哈雷站主建筑至近距安全营的短时转移 |
| 触发 | 冰架裂隙逼近，站体测量与路线桩显示继续扩展 |
| 证据 | 两份人员表、车辆座位、口粮、抵达点名、无线电和医务记录 |

7月2日，裂隙测量显示主建筑附近的活动带继续扩展，站长下令人员转往近距安全营。车辆分两批往返，科研设备留在原位，人员数日后返回。两份名单的姓名组成不同，却分别与车辆座位、口粮和抵达点名闭合。

调查组把两组名单、车辆日志、营地配给和医务记录分开封存。气象与地磁序列记录了站务中断的具体时段，哈雷公开站务卷没有记载永久关闭。异常集中在两套完整转移记录，而非站史本身。

## V09 1964 西线归队事件

| 字段 | 内容 |
|---|---|
| 日期 | 主复核自1964年11月6日开始；后续日程随联合调查逐日登记 |
| 地点 | 西线九号井以西、四十公里空地、失踪队营地与联合复核区 |
| 前史 | 1963苏联队失踪；随后出现语气平静的常规汇报，称“全员已经归队” |
| 目标 | 核对未施工交通线、寻找失踪队、判定路线是否可复现 |
| 参与 | 南极公约监督署协调，美、苏、中、北方委员会各派小队或联络员 |

第一阶段是地表集结：核对各国母图、工程计划、人员名单和返回权限。第二阶段从不同入口进入西线，不允许所有队共用一份地图。第三阶段发现苏联营地与已投入使用的四十公里交通线，现场有路基、倒木和磨损，却无施工设备和批准记录。第四阶段，总部收到“调查队已归队”和“仍在林中”的两份记录。第五阶段出现人员重叠，身份核验转入回返者观察组。

调查组采集路面剖面、树木倒伏方向、土方量、路线杆、车辆里程、无线电、工程领料、人员伤痕和返回签收。四十公里交通线由当地岩土、根板和现有构件组成，现场没有钢轨、机车或来源不明的大型工业品。材料分布符合“空间记忆重排既有物质”的现行边界。

美苏换届影响授权，中国小队依赖他国运输，北方委员会掌握早期底稿却缺少重货能力，南极公约监督署负责协调和版本登记。各国保留本国母图，联合调查只共享标记点和证据编号。事件正文仍随1964主线调查继续补录。

## 事件卷标准附件

标准卷由时间轴、参与名单、地点与入口、设备表、证据链、常规解释复核表、伤亡与后续、未决项八部分组成。缺件卷在封面注明“摘要”，结案章保持空白。
