# PALIS 档案工作台、审核与录入系统设计方案

## 目标

在现有 PALIS 网站中建立低资源的档案工作流：书记官可在工作台上传和修订内容，管理员审核并批复，批准的内容再录入九类正式档案。一个正式档案允许保留多位提交者的多份已批准材料，并具备可追溯的引用、版本、显示与封存状态。

## 范围与约束

- 现有 Cloudflare 静态网站继续承担公开档案、图片与前端界面。
- Supabase 免费版承担账号、数据库、低频审核通知及小型附件存储。
- 不提供公开注册；账号由管理员邀请创建。
- 不做实时协同编辑、全文文件重复存储、邮件正文群发或高频轮询。
- 所有公开档案沿用当前网站的复古 PALIS 排版，并显示 `VER 0.1 / 白幕初垂 / 已录入` 登记标记。
- 首批九份本地 HTML 档案卡作为内置模板来源，不直接作为用户上传的原始文件。

## 角色与账号

### 管理员

初始管理员为 `717652849@qq.com`，数据库角色为 `admin`。

- 邀请、停用与重新邀请用户。
- 为用户选择 `clerk`（书记官）或 `observer`（观察员）角色。
- 审核、批复、批准、退回、封存、下线和公开材料。
- 为批准材料录入档案编号、分类、版本、关联关系和展示状态。
- 设置母本与归档材料，处理引用档案的复核提示。

### 书记官

- 可进入书记官工作台。
- 可从九类模板创建新材料，也可向既有档案提交补充材料。
- 可编辑自己的草稿、提交审核、查看批复。
- 可对已公开档案或自己已提交的材料发起修订申请。
- 不能直接修改公开档案、审核结论或其他用户的私有草稿。

### 观察员

- 不可进入书记官工作台。
- 仅可浏览公开档案，以及管理员额外授权的档案。
- 不可编辑、提交、审核、查看草稿或用户管理。

### 邀请链路

```text
管理员 → 用户管理 → 输入邮箱、显示名、角色
→ 创建待激活邀请 → Supabase Auth 邮箱邀请
→ 受邀者验证邮箱 → profile 激活 → 进入角色对应界面
```

创建账号的服务密钥只放在 Supabase Edge Function。函数必须先验证当前调用者的 `admin` 角色；浏览器不保存或读取服务密钥。

## 档案内容与版本

每一份提交材料以结构化档案块保存，而不是保存任意原始 HTML。档案块支持：标题、摘要、段落、字段表、时间线、人物、图片、附件和引用标签。编辑器的预览使用现有网站的档案样式。

### 暂存与意外恢复

- 编辑器每次变化后在 800 毫秒内把当前草稿写入浏览器本地存储，不依赖网络。
- 登录且网络可用时，停止输入 5 秒后将同一草稿同步到 Supabase；连续输入不会产生高频请求。
- 页面显示“本地已暂存／云端同步中／云端已同步／离线暂存”四种状态。
- 意外关页、电脑闪退或网络中断后，再次打开同一模板或档案时自动发现恢复点，并让用户选择“恢复暂存”或“使用云端版本”。
- 成功提交审核后清除该提交版本的本地恢复点；退回修改时建立新的恢复基线。
- 同一账号在不同设备编辑时，以服务端修订号检测冲突，禁止静默覆盖较新的云端版本。

### 状态

```text
draft（草稿）
submitted（已提交）
in_review（审核中）
changes_requested（退回修改）
approved（已批准）
published（已录入公开）
sealed（封存）
offline（离线）
```

提交、审核和公开不是同一动作。书记官提交后不影响公开页；管理员批准并录入后，材料才可被公开显示。

### 多人共同档案

一个正式档案是容器，可拥有多份已批准提交材料。以 HZ-6 为例：

```text
HZ-6 / 事件档案
├─ 档案概览与母本说明
├─ 提交记录 01 / 提交者 A
├─ 提交记录 02 / 提交者 B
├─ 提交记录 03 / 提交者 C
├─ 提交记录 04 / 提交者 D
└─ 提交记录 05 / 提交者 E
```

档案页提供“概览／提交记录”切换。每一份已批准材料都显示提交者、提交时间、审核人、审核时间、版本和状态；不会被其他人的材料覆盖。

### 修订规则

- 书记官对已公开档案提交补充或修改时，生成新的修订草稿，不直接改写公开内容。
- 修订可指向“整份档案”或“某份提交材料”。
- 审核通过后，该目标材料产生新版本；旧版本保留在版本历史中。
- 页面标记修改者和修改时间，例如“修改者：XXXX / v0.1.1”。
- 已公开的旧版本在修订审核期间继续展示，直到新版本获批准。

## 管理员档案标记

管理员可为档案及提交材料设置独立标记：

| 标记 | 行为 |
|---|---|
| 母本 | 作为主题默认概览与主依据；可被后续档案引用 |
| 归档材料 | 已定稿的历史材料；可查阅并成为后续材料依据 |
| 公开显示 | 出现在公开档案页 |
| 封存 | 保留在系统中，仅管理员或获授权人员查看 |
| 离线 | 保留编号与状态，但不显示正文 |

归档材料或母本更新后，系统不会自动改写引用它的后续档案；而是将这些档案标为“引用需复核”，供管理员逐项确认。

## 引用系统

书记官编辑时可通过“引用档案”按钮或 `@` 搜索档案编号、类别和名称。选中后插入结构化引用，不复制目标正文。

```text
HZ-6 队伍采集到 [S01 / 白壳虫] 样本。
```

- 公开页面中引用可点击并打开目标档案窗口。
- 每份档案显示反向引用列表，例如“被 HZ-6 / 提交记录 02 引用”。
- 目标档案封存或离线时，引用保留，但显示其状态且不泄露正文。
- 公告与版本说明也使用同一引用组件，因此“本版新增人物与事件”可直接点击打开档案窗口。

## 审核、批复与站内回信

管理员审核时可查看原版本、申请版本、修改说明和引用变化。审核决定为“批准”或“退回修改”，必须附批复。

```text
P42 / 顾功叙人员卷
状态：需修改
批复：请补齐任职年代与地震重力组的资料来源。
审核人：717652849@qq.com
```

批复写入站内收件箱。第一版不发送正文邮件，只通过登录后的未读通知提醒用户，以降低成本；邀请邮件仍由 Supabase Auth 发送。

## 档案录入系统

管理员在批准后进入“录入确认”窗口：

1. 指定九类分类。
2. 分配或确认档案编号，如 `P47`、`EV11`、`O25`。
3. 填写版本号、录入说明和关联档案。
4. 设置母本、归档、公开、封存或离线状态。
5. 发布到当前网站的正式档案索引。

正式档案页显示紧凑的录入章：

```text
VER 0.1 / 白幕初垂
PALIS REGISTERED RECORD
```

图标采用本地内联 SVG，不依赖运行时图标请求。视觉语言为复古软盘、档案夹、钢笔、印章、信封、批准勾选和退回箭头，沿用 0.1 的红／黄／蓝登记色。

## 数据模型

| 表 | 责任 |
|---|---|
| `profiles` | 用户身份、显示名、角色、启用状态 |
| `user_invites` | 邀请、角色、到期与激活状态 |
| `archive_templates` | 九类初始模板 |
| `archives` | 正式档案容器、编号、分类、公开状态、母本标记 |
| `archive_contributions` | 某档案下的独立提交材料与提交者 |
| `archive_versions` | 材料和档案级修订的不可变版本历史 |
| `archive_reviews` | 审核决定、批复、审核人和时间 |
| `archive_references` | 正向／反向引用关系与复核状态 |
| `archive_notifications` | 站内回信与未读状态 |
| `archive_attachments` | 附件元数据和 Storage 路径 |
| `observer_access` | 对封存档案的额外观察员授权 |

数据库启用 RLS：书记官只读写自己的草稿与通知；观察员只读公开或获授权档案；管理员拥有审核和录入权限。所有正式公开写入由管理员受控动作完成。

## 低资源策略

- 正文保存为结构化 JSON，不保存重复的 HTML 文件。
- 首批九份模板随网站部署；用户附件按单个 5 MB、单份提交最多 10 个限制。
- 站内通知按登录时读取，不使用常驻 websocket 或轮询。
- 暂存先写浏览器本地，云端采用 5 秒防抖同步，避免每次按键都写数据库。
- 图标内联或本地打包，不从 Iconify 运行时加载。
- 公开档案继续由 Cloudflare 静态资源提供；只有编辑、审核和录入动作访问 Supabase。

## 实施阶段

1. Supabase 项目、Auth、管理员初始化、RLS 与邀请 Edge Function。
2. 九类模板导入、档案块格式和本地预览渲染。

4. 管理员审核台、批复收件箱、版本历史与用户管理。
5. 正式档案录入、多人提交材料切换、母本／归档／公开／封存／离线标记。
6. 引用编辑器、反向引用、公告引用与“引用需复核”。
7. 低资源限制、权限测试、移动端与现有档案页面接入验证。

## 验收标准

- 管理员可邀请书记官和观察员；观察员无法进入书记官工作台。
- 书记官可新建、提交、补充并修订档案，且无法直接改写公开内容。
- 编辑中断后可恢复本地暂存，网络恢复后可低频同步云端，并能识别跨设备版本冲突。
- HZ-6 等单一档案可显示多名提交者的多个已批准材料，并可切换查看。
- 每份材料和修订都显示提交者／修改者、审核人与版本。
- 管理员可审核、批复、录入、设为母本／归档／公开／封存／离线。
- 编辑器和公告都能插入档案引用，点击引用打开目标档案；封存和离线档案不泄露正文。
- 正式档案显示 `VER 0.1 / 白幕初垂` 录入标记。
