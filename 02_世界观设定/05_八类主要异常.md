# 05 八类主要异常

| 异常 | 表现 | 事件级后果 |
|---|---|---|
| 人数不闭合 | 餐具、床位、医疗检查、照片人数不同 | 补给和返程座位按错误人数发放 |
| 行程缺段 | 地图、里程、时间和脚底样本无法对上 | 救援队抵达错误地点 |
| 归队矛盾 | 总部记录显示队伍归来，但队伍仍在林中呼叫 | 搜救流程被关闭 |
| 证据互斥 | 胶片、日志、样本各自支持不同版本 | 公开调查选择能压低伤亡的版本 |
| 职位错置 | 不知道是谁执行了必要工作 | 下一次行动把关键任务交给错误岗位 |
| 地理闭合失败 | 两国队伍各自走对，却在同一锚点互相指控越界 | 外交危机压过救援 |
| 人员重叠 | 同一身体被两套身份档案认领 | 伤员交换和家属通知无法处理 |
| 国家组织性格与元首回响 | 同国机构无通联却做出相似行政动作，最高层误记南极简报 | 预算、撤离和保密口径沿错误记忆执行 |

## 5.9 八类异常如何连成一件事

一次事件最好不要只展示一种异常。白渊事件应让路线、人员、证据、归队流程和行政后果互相咬合。

## 5.10 异常如何改变具体事件

异常必须落到行动后果：搜救被取消、补给发错、伤员被错认、家属通知互斥、公开新闻选择了错误版本。

## 5.11 物理与生态伴随异常

八类主要异常仍然是行政和剧情后果的分类，不额外增加“第九类”。下列超自然现象作为八类异常的物理或生态伴随证据出现：

| 伴随现象 | 可见表现 | 通常连接的主要异常 |
|---|---|---|
| 空间记忆 | 未施工路线形成倒木和压实地面；同号站点实体重复 | 地理闭合失败、行程缺段 |
| 生态记忆 | 根板层、敲击节律或迁徙提前对应任务编号与点名 | 证据互斥、归队矛盾、国家组织性格回响 |
| 白余量 | 生态生物量长期高于热流与化学能预算，实验却无法稳定取能 | 证据互斥、职位错置 |
| 版本守恒 | 新版本获得物资、人员或路线完整性，旧版本出现对应缺口 | 人数不闭合、人员重叠、归队矛盾 |
| 提前回声 | 无线电、脚印或生态变化先于行动出现，但只包含已经进入计划链的信息 | 行程缺段、归队矛盾 |

伴随异常本身不能替代事件后果。例如“树木会记住广播”只是气氛；只有它导致队伍采用错误呼号、关闭搜救或认领错误人员时，才构成完整白渊事件。
