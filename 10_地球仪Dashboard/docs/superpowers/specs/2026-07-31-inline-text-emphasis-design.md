# 档案正文加粗与遮蔽设计

## 目标

为所有可编辑档案正文提供统一的加粗与 SCP 式遮蔽能力，同时保持现有档案表单、正式排版和历史版本结构不变。

## 用户体验

- 正文输入区域上方提供两个复古风格工具按钮：`B`（加粗）与 `█`（遮蔽）。
- 用户选中文字后点击按钮即可应用效果，再次点击可取消对应效果。
- 没有选中文字时不改变内容，并保持输入焦点。
- 正式档案中，加粗文字使用当前正文的粗体；遮蔽文字默认显示为黑色遮挡条。
- 鼠标悬停或键盘聚焦遮蔽条时显示原文；无鼠标设备使用点击切换显示状态。
- 遮蔽内容参与正文保存、修改继承、历史版本和正式发布，不改变标题、固定字段、档案编号或分类字段。

## 数据与渲染

- 编辑文档继续使用现有 schema，新增可选的行内标记集合；没有标记的旧档案按原文本渲染。
- 标记必须经过规范化，范围不能越过正文内容边界，重叠标记按加粗与遮蔽两个独立维度合并。
- 编辑器保存和读取时保留标记；正式档案渲染器将标记转换为带语义的 `<strong>` 与可聚焦遮蔽元素。
- 遮蔽元素使用按钮或等价可聚焦控件，提供可访问名称，并支持 `:hover`、`:focus-visible` 和点击状态。

## 兼容与安全

- 纯文本旧记录无需迁移即可继续显示。
- 用户输入仍通过现有文本转义与内容规范化流程，禁止把正文标记当作任意 HTML 执行。
- 不改变现有档案视觉基线、滚动方式、附件逻辑或审核权限。

## 验证

- 测试选区加粗和遮蔽的增删、旧文档兼容、保存读取往返、修改/历史版本继承。
- 测试正式渲染包含语义加粗和可聚焦遮蔽，不直接注入未转义正文。
- 测试所有档案模板的编辑区域挂载相同工具行为。
