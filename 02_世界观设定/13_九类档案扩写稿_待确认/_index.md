## 确认后的入站顺序

1. 先确认 `10_一致性审计与待确认项.md` 中的关键问题，尤其是 HZ-6 年份、物种证据年代和站名口径。
2. 再逐类确认正文。确认时可以删减，但不应让网站摘要反过来覆盖母稿。
3. 运行`npm run archive:sync`从母稿生成网站正文，不直接修改`src/archive-longform.js`。
4. 入站后逐条比对条目数、编号、坐标和年份，不在前端临时补设定。
