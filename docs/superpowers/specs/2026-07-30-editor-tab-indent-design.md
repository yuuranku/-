# 全编辑区 Tab 段落缩进

## 目的

让书记官工作台内所有可编辑的多行文字框具有一致的中文段落输入方式，同时不改变单行控件既有的键盘焦点导航。

## 交互约定

- 在任意可编辑 `textarea` 中按 `Tab`，阻止浏览器切换焦点，并在当前行插入两个全角空格（`　　`）。
- 选中跨越多行的文本时按 `Tab`，每个选中行的行首都插入一个缩进。
- 按 `Shift + Tab` 时，移除当前行或每个选中行行首的一个完整缩进；没有缩进时不改动内容。
- 单行输入框、下拉框、按钮、只读控件及文件选择控件不拦截 `Tab`，维持原有焦点行为。
- 输入后派发标准 `input` 事件，使现有自动暂存、同步提示、引用菜单和提交逻辑继续工作。

## 范围

功能以工作台表单容器为边界，覆盖档案固定字段、自定义内容、审核意见、工作便签及后续在该工作台中新增的可编辑多行框。它不改变公开档案的视觉样式，也不改变服务器存储格式；全角空格作为正文字符随现有数据流保存、重开与发布。

## 实施方式

在工作台的顶层表单事件处理中新增一个可复用的键盘处理器，使用事件委托识别可编辑的 `textarea`。处理器根据选区的起止位置对文本行进行插入或反向移除，再恢复选择范围和光标位置。这样动态添加的自定义条目也会自动获得相同行为，无需逐个绑定监听器。

## 验证

- 单行按 Tab 不被拦截。
- 单个正文行按 Tab 插入两个全角空格。
- 多行选择按 Tab 为各行插入缩进。
- Shift+Tab 只移除完整的行首缩进。
- 修改会触发现有自动暂存路径。
- 现有工作台与发布构建测试保持通过。
