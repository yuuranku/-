# 08 异常事件档案

异常条目记录已经发生的闭合失败。调查顺序从普通事故、文书错误、设备缺陷、政治删改和翻译问题开始，剩余矛盾另列异常附页。

## A01 1947.02.11 E-14返航计数事件

| 字段 | 内容 |
|---|---|
| 地点 | 罗斯海临时航空营地 |
| 事件型 | 人数不闭合 |
| 首次异常 | 飞机按六人起飞，七人完成落地后的手续 |
| 固定证据 | 起飞单、座位、燃油、口粮支持六人；返航点名、医检和工资附件支持七人 |

先排查临时搭乘、重复姓名、地勤误入队列、返航后换班和表格誊写。异常成立条件是第七人同时拥有有效身份和返航手续，却没有起飞位置、口粮消耗或座位。

影响只限E-14任务及其后续档案，不让整个跳高行动人数变化。处理方式是分存六人飞行卷和七人返航卷，禁止把第七人简单删成“地勤”。

## A02 1948.01.22 龙尼航片重复谷地

| 字段 | 内容 |
|---|---|
| 地点 | 菲尔希纳冰架西缘 |
| 事件型 | 证据互斥 |
| 首次异常 | 不相邻航线的两卷底片出现同一谷地边缘和相同云隙 |
| 固定证据 | 原底片边码、飞行本、太阳高度、云层、相机和冲洗记录 |

先排查底片重装、复制错贴、飞行员重复航段、暗房套印和后期裁切。只有原底片连续边码、前后帧和曝光状态都支持各自航线时，才标“重复景观”。

异常不说明谷地会瞬移，也不说明龙尼拍到白渊全貌。处理方式是保留整卷，不只剪下相似两帧。每份复制件记录裁切范围和代次。

## A03 1949.11.03 联合钻探箱号倒置

| 字段 | 内容 |
|---|---|
| 地点 | 海湾中转站 |
| 事件型 | 证据互斥 |
| 首次异常 | 两只样本箱同时拥有对方封条、重量和签收记录 |
| 固定证据 | 木箱纹理、铅封、秤单、交接照片、内部样本和包装纤维 |

调查组检查了人为调包、翻译、箱盖互换、秤具偏差和同型号封条。两条来源链各自完整，却指向相反箱体；报告只记录这一结果，没有给出交换机制。

处理方式是停止重新贴签，把箱体、箱盖、内衬和样本分别编号。后续引用必须说明采用哪一方交接链。

## A04 1952.08.19 HZ-6第三次点名

| 字段 | 内容 |
|---|---|
| 地点 | 暮色针叶层样本线 |
| 事件型 | 人数不闭合 |
| 当前条目 | 录音出现第六个回答，五人复述都否认听见，却在表格留出第六行 |
| 状态 | HZ-6前置巡线独立事故；与11月18—19日主任务分卷 |

A04发生在1952年8月19日，是HZ-6线路的前置巡线。任务用于校准无线电中继、路线标记和点名程序，参与者与11月五人主任务分别登记。录音带、值班表和留有第六行的点名原件单独封存。

调查人员检查了回声、串频、另一队呼号、记录员预留空行和磁带剪接。第六个回答仍留在原带，五名在场人员的初次口述都称没有听见额外声音。11月主任务采用修订后的点名程序，事故卷没有把A04并入动物接触时序。

## A05 1953.06.07 帕尔默中继室双值班

| 字段 | 内容 |
|---|---|
| 地点 | 帕尔默地临时中继室；该地名早于美国正式启用Palmer Station站名 |
| 事件型 | 人员重叠 |
| 首次异常 | 同一夜班留下两套完整日志与消耗记录 |
| 固定证据 | 电报码、机械钟、咖啡配给、钥匙、门锁、交班签名和分开口述 |

先排查夏令时／时区、交叉换班、房间同名、日志复制、值班员互用呼号。异常成立时，两组人员均不应知道另一组的隐私，只能准确描述同一设备和不同房间版本。

处理方式是把人员分开观察、停用该呼号、封存原纸带。该设施按“帕尔默地临时中继室”归档，不与后来建立的帕尔默站合并。

## A06 1958.09.14 南九号线失联归队

| 字段 | 内容 |
|---|---|
| 地点 | 中苏联合内陆线 |
| 事件型 | 归队矛盾 |
| 首次异常 | 归队手续比搜救命令早四小时完成，原队无线电仍在呼叫 |
| 固定证据 | 中苏派遣表、医检、签名、装备回收、无线电方向和搜救命令 |

先排查电报时区、命令签发与送达时间、预填归队表、呼号被盗用和无线电回放。异常成立需要归队人员的身体检查和装备磨损都可核验，同时远端信号仍能被多站定向。

归队人员进入短期隔离，医生核对指纹、血型、旧伤、牙齿和个人物件；无线电设备、电池与纸带由另一组人员封存。中苏双方分别保存副本。这套处置后来成为昆仑工程证据制度的起点。

## A07 1962.07.02 哈雷转移双清单

| 字段 | 内容 |
|---|---|
| 地点 | 哈雷湾站至近距安全营 |
| 事件型 | 人数不闭合 |
| 首次异常 | 两份不同名单分别与车辆座位、口粮和抵达人数闭合 |
| 固定证据 | 车辆牌号、座位、油耗、口粮、出发点名、抵达点名和医务记录 |

调查组逐项核对分批转移、人员改乘、重复昵称、空座装货和中途折返，并按姓名、衣物、铺位和伤病比较两份名单。两组记录仍分别与车辆和营地消耗闭合。

事件由冰架裂隙逼近触发，人员从主建筑转移到近距安全营，数日后返回。两组人员表和物资闭合表分别保存，调查卷没有制作合并后的“最终名单”。

## A08 1964.11.06 西线未施工路段

| 字段 | 内容 |
|---|---|
| 地点 | 南极公约监督署西线复核区 |
| 事件型 | 地理闭合失败 |
| 首次异常 | 调查组带回一条已投入使用的40公里交通线记录，工程档案证明从未批准、领料或施工 |
| 固定证据 | 路面剖面、倒木、土方量、磨损、路线杆、车辆里程、工程计划和领料 |

先排查自然兽道、旧河道、冰退地貌、未归档军工项目、地图误投影和不同国家同名路线。异常成立必须有至少两国现场测量和两条独立工程档案链。

道路由当地岩土、根板和沿线已有构件组成。现场未见钢轨、机车或成套工业设施；发现的螺栓与路标材料都能对应到附近库存缺口。

南极公约监督署暂停道路的正式命名和工程验收。各国调查组保留母图，只在联合图上共享实测标记点。四十公里路段构成归队事件的地理证据，人员身份与总部双重记录另卷调查。

## A09 1943.02.09 寒区热钻供电缺口

| 字段 | 内容 |
|---|---|
| 地点 | 战时寒区热钻试验场 |
| 事件型 | 职位错置 |
| 首次异常 | 热钻耗电长期超出供电台账，三班电工的值勤表都不认领当班开钻 |
| 固定证据 | 供电纸带、三班值勤表、钻机工时、燃料领用、配电盘读数 |

先排查电表误差、班次交接重叠、记录誊写、双人操作和临时借调。异常成立条件是耗电与钻进工时都可核对，却没有任何一班的值勤表把这段开钻记在自己名下。

影响限于该试验场的工时与供电结算，不改动整条热钻技术链。处理方式是三班原始值勤表分别封存，禁止合并成一份“责任工时”，也不把缺口摊派给最近一次换班。

## A10 1951.03.14 迪蒙·迪维尔海岸多绘

| 字段 | 内容 |
|---|---|
| 地点 | 迪蒙·迪维尔海岸航测段 |
| 事件型 | 地理闭合失败 |
| 首次异常 | 法方独立航片在英美底稿的同一坐标上多绘出一条内陆谷口 |
| 固定证据 | 法方原底片、英美格网、太阳高度、海岸交会线、飞行本 |

先排查投影基准、格网换算、镜头畸变、云影错认和后期裁切。异常成立条件是三方底片各自连续、曝光正常，却在同一坐标上给出有谷口与无谷口两种海岸。

影响限于该海岸段的联合图，不改动各国已印海岸线。处理方式是法、英、美三套坐标分别保留，该谷口按“单方多绘”登记，不并入联合索引，也不据此改绘他国母图。

## A11 1956.11.20 黑湖声呐回声三读

| 字段 | 内容 |
|---|---|
| 地点 | 黑湖水—气交界（回声探井前身） |
| 事件型 | 证据互斥 |
| 首次异常 | 一次换能器投放的撞击声，在声呐纸带上比投放动作早约三秒出现 |
| 固定证据 | 声呐纸带、投放时序表、换能器编号、走带速度、多路径记录 |

先排查时钟漂移、纸带走速、多路径反射、串频和纸带剪接。异常成立条件是投放时序与撞击声各自可核，声呐带却把撞击稳定记在投放之前。

影响限于该扇区的声呐解释，不据此绘制可步行地图。处理方式是同一撞击声的套管、冰裂和多路径三套底回波并存封存，投放时序表另卷保存，不为对齐时间而修改任一方。

## A12 1957.07.01 联合索引里程缺段

| 字段 | 内容 |
|---|---|
| 地点 | 国际地球物理年联合索引区 |
| 事件型 | 行程缺段 |
| 首次异常 | 归一坐标后，同一条测线的里程在三国记录里同时短少了同一段 |
| 固定证据 | 三国里程表、坐标基准、测线桩号、行进时间、脚底样本 |

先排查基准换算、桩号误抄、单位混用、复测遗漏和誊写。异常成立条件是三国里程、桩号和时间各自闭合，合到同一基准后却共同缺失同一段路。

影响限于联合里程索引，不改动各国原始测线。处理方式是三国里程表分别保留，缺失段按“未闭合里程”标注，救援与补给不按归一后的总里程计算。

## A13 1959.12.01 议定书双附件

| 字段 | 内容 |
|---|---|
| 地点 | 南极条约签署地／联合国南极管理局 |
| 事件型 | 地理闭合失败 |
| 首次异常 | 同一批入口的管辖权，公开条约附件与秘密监督议定书附件互斥，两份都盖生效章 |
| 固定证据 | 两份附件正本、生效章、签署名录、入口清单、发文号 |

先排查誊写、翻译、附件错装、盖章日期和版本代次。异常成立条件是两份附件的签署、盖章和入口清单各自完整，却把同一批入口划给不同管辖方。

影响限于这批入口的管辖登记，不影响条约公开条款。处理方式是两份附件分别封存，相关入口按“管辖争议”登记，任何一方引用都必须注明所据附件。

## A14 1962.10.24 多语种确认广播

| 字段 | 内容 |
|---|---|
| 地点 | 民用短波频段／监督署监听站 |
| 事件型 | 人数不闭合 |
| 首次异常 | 一段多语种“确认安全”广播点到的名单里，既有已列失踪、也有尚未派出的人 |
| 固定证据 | 录音、播出时段、台站排班、失踪名册、在编与未派出名单 |

先排查串台、录音回放、伪造广播、时区错记和名单误录。异常成立条件是录音、播出时段可核，名单里的人却分属已失踪、在编和尚未派出三种互斥状态。

影响限于监听记录，不据此改动失踪或在编名单。处理方式是录音与译文单独封存，广播点到的人各自维持原状态，不因一段“确认安全”提前销案或补派。

## A15 1963.08.19 黑湖血样病历互斥

| 字段 | 内容 |
|---|---|
| 地点 | 南极回返者接收医院 |
| 事件型 | 人员重叠 |
| 首次异常 | 同一名黑湖回返者，两家医院、两个月份的血型与病历互斥，两份都通过校验 |
| 固定证据 | 两份病历、血型单、指纹、牙记、入院签收、样本编号 |

先排查抽错管、贴错标签、翻译、同名同姓和系统串号。异常成立条件是两份病历的指纹、牙记都指向同一人，血型与既往史却互相排斥，且各自通过复核。

影响到输血配型与家属通知。处理方式是两份病历分别封存、暂停按任一份配血，家属通知挂“待核”，不合并成一份“最终病历”。

## A16 六十年代中期 元首回响封存令

| 字段 | 内容 |
|---|---|
| 地点 | 某参与国本土机关与最高层简报室 |
| 事件型 | 元首回响 |
| 首次异常 | 同国两个无通联机关同期发出措辞几乎一致的封存令，最高层简报里记着一次从未发生的南极汇报 |
| 固定证据 | 两份封存令、发文号、通联记录、简报纪要、值班签到 |

先排查抄送、口头传达、共用模板、秘书误记和事后补录。异常成立条件是两份封存令的发文号和签发各自独立、无通联记录，措辞却高度一致，且最高层纪要所记的汇报在任何日程上都不存在。

影响到该国的封存口径与预算安排。处理方式是两份封存令按各自发文号分存，简报纪要相关段落附“记忆待核”注记，后续引用不得把不存在的汇报当作依据。

## 异常严重度

| 级别 | 含义 | 行动 |
|---|---|---|
| observed | 单一来源或普通解释尚未排尽 | 保存原件，继续复测 |
| warning | 两条独立来源冲突，影响局部行动 | 限制使用相关路线、名单或样本 |
| critical | 冲突会直接改变救援、身份或路线安全 | 停止常规行动，启动监督署联合复核 |

严重度不表示“超自然强度”。一处普通的错误名单也可能因影响救援而列critical；一份怪异胶片若不改变行动，仍可只列warning。
