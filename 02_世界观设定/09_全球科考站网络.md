# 09 全球科考站网络

各国入口的坐标、类型、容量和地下落点详见[`09A_白渊入口与下降点网络_1964.md`](09A_白渊入口与下降点网络_1964.md)。

## 9.1 站点分级

| 层级 | 说明 |
|---|---|
| 表层站 | 海岸、冰架或中央高原上的公开基地，负责船运、航空、气象与人员集散 |
| 井口站 | 位于中央冰盖的钻井、货梯和隔离设施，可伪装成冰芯仓库或危险裂隙区 |
| 林下站 | 白渊内部的常驻或临时营地，对外不存在 |
| 争议站 | 只存在于广播、地图、邮戳或幸存者证词中的地点 |

## 9.1A 入口分级

| 类型 | 说明 |
|---|---|
| A级重型入口 | 可让整辆履带车辆或大型构件通过；1964年只有美国蓝阶斜道与苏联红坡道 |
| B级人员货运井 | 有固定吊笼、换装层与隔离室，承担常规轮换 |
| C级轻型入口 | 天然裂口、小型吊舱井或窄斜道，只能进人员和轻货 |
| D级探井 | 只能下放仪器和取样器 |
| E级应急／争议通道 | 季节性、单向、失联或不纳入正常救援计划 |

## 9.2 各国站网的风格

| 国家／组织 | 站网骨架 | 常见问题 |
|---|---|---|
| 美国 | 麦克默多是后方母站，南极点站直接锚定分散的K系入口；伯德站承担地球物理与账目分流 | 航空与影像能力强，档案版本繁多 |
| 苏联 | 和平站—东方站履带车主干线支撑曙光一号、红坡道、湖钟探口与泰加站；新拉扎列夫站是替代人员线 | 拥有最大地下运输能力，命令体系严密 |
| 中国 | 借东方站公开运输线抵达海燕中转点，再分流至昆仑一号、松岭裂口和红签探井 | 没有公开中国站，两条人员入口都很小，依靠手绘、多证据核对和实物留存 |
| 英国 | 哈雷湾站锚定西部入口方向；锡格尼、F站与希望湾构成外围监听、档案与人员转签网 | 擅长档案封存与无线电，但缺乏重货内陆线 |
| 法国 | 迪蒙·迪维尔—夏尔科旧站路线支撑夏尔科斜廊、奥尔菲探井与林缘站 | 植物分类、纪录片与旧站档案 |
| 澳新 | 戴维斯—莫森路线杆系统直接支援威尔克斯湿门；威尔克斯与斯科特基地承担东部箱号和外围运输 | 小型测绘营多，路线杆与里程偏差常见 |
| 南美国家 | 阿根廷与智利早期站网 | 同一地点常有两套合法地名 |

白渊总体坐标、分区和物理参数见[`附录B_白渊核定坐标与物理参数_1964.md`](附录/附录B_白渊核定坐标与物理参数_1964.md)。入口核定坐标以09A为准；林下站点仍允许保留互斥坐标版本。

## 9.3 入口依托规则

- 地图必须把公开科考站—内陆雪道—入口画成连续链；只画井口而不画地表依托，会错误暗示入口可以独立生存。
- 入口坐标之间保持数百公里级分离。最近的不同国家入口约相隔256公里，多数国家主扇区相隔更远；地下空间仍可因空间页折叠而出现邻接。
- 科考站只负责现实后勤与档案外壳，不等于站内大多数人员知晓白渊。
- 海岸站到内陆入口的直线距离不等于运输里程，地图连线只表示走廊归属，不表示可以按大圆线直接行驶。
